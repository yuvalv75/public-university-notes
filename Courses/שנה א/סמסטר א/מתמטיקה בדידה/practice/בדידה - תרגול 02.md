# מתמטיקה בדידה - תרגול 2

יהיו P,Q פרדיקטים מעל $`{}\mathbb{Z}{}`$
הוכיחו\הפריכו:
א


```math
\begin{gathered}
\forall a:(P(a)\vee Q(a))\implies(\forall a:P(a))\vee(\forall a:Q(a))\\
P(a)=\text{אי זוגי}\\
Q(a)=\text{זוגי}
\\ T\implies F \ \ \ \ \ \text{הפרכה}\\
\end{gathered}
```


ב


```math
\begin{gathered}
\forall a:(P(a)\vee Q(a))\impliedby(\forall a:P(a))\vee(\forall a:Q(a))\\
\text{נפצל למקרים }
\\
\text{בשני המקרים T גורר T }
\end{gathered}
```






קבוצה היא אוסף של איברים
אם איבר a שייך לקבוצה B כותבים $`{} a\in B{}`$ 
אם כל איברי קבוצה A שייכים גם לקבוצה B אומרים ש A מוכלת בB סימון: $`{}A\subseteq B{}`$ 
אז A=B אם $`{}A\subseteq B {}`$ וגם $`{}B\subseteq A{}`$.
