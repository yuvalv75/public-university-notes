# מתמטיקה בדידה - תרגול 6

נתון A,B קב'
יחס מA ל-B הוא תת קבוצה של $`{}A\times B{}`$ 
יחס R מA ל-B נקרא <u>חד ערכי</u> אם


```math
\forall a\in A\forall b_{1},b_{2}\in B:(a,b_{1})\in R\land(a,b_{2})\in R\implies b_{1}=b_{2}
```



יחס R מA ל-B נקרא <u>שלם</u> אם


```math
\forall a\in A\exists b\in B:(a,b)\in R
```


יחס חד ערכי ושלם הוא פונקציה
סימון:


```math
\begin{gathered}
f:A\to B\\
f(a)=b\\
a\mapsto b
\end{gathered}
```




תהי A קבוצה. פונ' הזהות:


```math
\begin{gathered}
Id_{A}: A\to A\\
a\mapsto a
\end{gathered}
```


תהי $`{}f:A\to B{}`$ 
אז A נקראת התחום של f
אז B נקראת הטווח של f

התמונה של f היא:


```math
\mathrm{Im}f:=\left\{ b\in B|\exists a\in A:f(a)=b \right\}
```


תהי $`{}f:A\to B{}`$ 
היא נקראת <u>חד חד ערכית</u> אם:


```math
\forall a_{1},a_{2}\in A:f(a_{1})=f(a_{2})\implies a_{1}=a_{2}
```


תהי $`{}f:A\to B{}`$ 
היא נקראת <u>על</u> אם:


```math
\forall b\in B\exists a\in A:f(a)=b
```



### טענה\הגדרה
תהיינה A,B,C קבוצות,
ו- $`{}f:A\to B{}`$ , $`{}g:B\to C{}`$ פונק'
אזי ההרכבה $`{}g\circ f:A\to C{}`$ המורכבת על ידי $`{}g\circ f(a)=g(f(a)) {}`$ היא פונקציה



תהי $`{}f:A\to B{}`$ פונק'
תהיינה $`{}X\subseteq A,Y\subseteq B{}`$ תק
תמונה חלקית של X:


```math
f[X]:=\left\{ f(x):x \in X \right\} \subseteq B
```


התמונה ההפוכה של Y:


```math
f^{-1}[Y]:=\left\{ a\in A|f(a)\in Y \right\}
```
