# הוכחה
יהי R יחס סדר מלא על A


```math
\begin{gathered}
\implies\\
\text{ נכון בכל יס"ח } \\
\text{ מקסימלי } x\ \text{נניח } \impliedby\\
a\in A\text{ יהי } \\
\text{ נחלק למקרים } \\
1)\\
\text{ סיימנו } \impliedby(a,x)\in R\\
2)\\
(a,x)\notin R\\
\text{ כיוון שזהו יחס סדר מלא  } \\
(x,a)\in R\\
\downarrow \text{מקסימלי }x\\
x=a\\
(x,x)\notin R \text{ וקיבלנו } \\
\text{ סתירה }\\ \\
(a,x)\in R\text{ סהכ קיבלנו } \\
\text{ מקסימום } x\text{ לכן}
\end{gathered}
```



# פונקציות
### הגדרה:
יהי R יחס מA ל-B
> 1) נקרא חד ערכי כאשר                $`{}\forall a\in A\forall b_{1},b_{2}\in B:aRb_{1}\land aRb_{2}\implies b_{1}=b_{2}{}`$
> 2) R נקרא שלם כאשר                  $`{}\forall a\in A\exists b\in B:aRb{}`$
> 3) R נקרא חד חד ערכי כאשר        $`{}\forall a_{1},a_{2}\in A\forall b\in B:a_{1}Rb\land a_{2}Rb\implies a_{1}=a_{2}{}`$
> 4) R נקרא <u>על</u> כאשר                      $`{}\forall b\in B\exists a\in A:aRb{}`$


### הגדרה
יחס F מA ל-B שהוא
חד ערכי ושלם נקרא פונקציה מA ל-B
כאשר f פונקציה מA ל-B. מקובל לסמן $`{}f:\overbrace{ A }^{ \text{תחום} }\to \overbrace{ B }^{ \text{טווח} }{}`$ 
וכאשר $`{}(a,b)\in f{}`$ מקובל לסמן $`{}f(a)=b{}`$ ואומרים ש "a הוא מקור של b"


נגדיר פונקציה $`{}f:\mathbb{N}\to \mathbb{Z}{}`$


```math
\begin{gathered}
f(x)=x-4\\
\text{ לא על } f \ \text{נוכיח}\\
-5\in \mathbb{Z}\\
\text{ נוכיח שאין לו מקור } \\
\text{ כך ש } x \in \mathbb{N}\text{ נב"ש שקיים } \\
f(x)=-5\\
x-4 = -5\\
x=-1\\
\text{ סתירה }
\end{gathered}
```



נגדיר פונקציה $`{}f:\mathbb{Z}\to \mathbb{Z}{}`$


```math
\begin{gathered}
f(x)=x-4\\
\text{ על } f \ \text{נוכיח}\\
y\in \mathbb{Z}\\
x:=y+4 \text{ ניקח } \\
\text{ ואכן } \\
(y\in \mathbb{Z} , 4\in \mathbb{Z} \text{ כי}) x \in \mathbb{Z}\\
f(x)=f(y+4)=y+4-4=y
\end{gathered}
```



### הגדרה
תהי $`{}f:A\to B{}`$ פונקציה.
נגדיר 


```math
\begin{gathered}
\overbrace{ I_{m} }^{ f\text{ התמונה של} }f:=\left\{ b\in B\middle|\begin{array}{}
\exists a\in A \\
f(a)=b
\end{array} \right\}=\left\{ f(a)\middle|a\in A \right\} \subseteq B\\
\\
f:A\to B\\
\text{ על } f\\
\iff\\
I_mf=B
\end{gathered}
```


### הגדרה
תהינה $`{}f:A\to B{}`$, $`{}g:B\to C{}`$ פונקציה
נגדיר $`{}g\circ f: A\to C{}`$ "f הרכבה g"


```math
\forall a\in A:(g\circ f)(a)=\boxed{g(f(a))}
```

אזי $`{}g\circ f:A\to C{}`$ היא פונקציה
