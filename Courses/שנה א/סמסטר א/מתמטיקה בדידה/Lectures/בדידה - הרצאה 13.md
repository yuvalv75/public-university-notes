### תמונה חלקית ותמונה הפיכה
הגדרה:  תהי $`{}f:X\to Y{}`$ פונקציה
1)
לכל $`{}A\subseteq X{}`$ נגדיר


```math
\begin{gathered}
f[A] := \left\{ y\in Y\middle| \begin{array}{}
\exists a\in A: \\
f(a)=y
\end{array} \right\} \\
=\left\{ f(a)|a\in A \right\} \subseteq Y\\
\\
\text{במילים אחרות } \\
y \in f[A] \iff\exists a \in A: f(a) = y
\end{gathered}
```


זאת התמונה החלקית של A תחת f

2)
לכל $`{}B\subseteq Y {}`$ נגדיר


```math
\begin{gathered}
f^{-1} [B]=\left\{ x \in X|f(x)\in B \right\}  \subseteq X\\
\\
\text{במילים אחרות } \\
x \in f^{-1}[B]\iff f(x)\in B
\end{gathered}
```


זאת התמונה ההפוכה של B תחת f


**התמונה ההפיכה מוגדרת גם כאשר הפונקציה אינה הפיכה**


# הערות
תהי $`{}f:X\to Y{}`$ פונקציה
1)


```math
f[X]=\mathrm{Im}f
```


2)


```math
f[\emptyset]=\emptyset
```


3)


```math
\begin{gathered}
f^{-1}[Y]=X\\
\text{ פונק' ובפרט שלמה } f\ \text{לבית}
\end{gathered}
```


4)


```math
f^{-1}[\emptyset]=\emptyset
```



### טענה
תהי $`{}f:X\to Y{}`$ פונקציה
1)
יהיו $`{}A_{1},A_{2} \subseteq X{}`$ אזי


```math
f[A_{1}]\subseteq f[A_{2}] \impliedby A_{1}\subseteq A_{2}
```


2)
יהיו $`{}B_{1},B_{2} \subseteq Y{}`$ אזי


```math
f^{-1}[B_{1}]\subseteq f^{-1}[B_{2}] \impliedby B_{1}\subseteq B_{2}
```



### הוכחה
תהי $`{}f:X\to Y{}`$ פונקציה
1)


```math
\begin{gathered}
A_{1}\subseteq A_{2} -\text{כך ש}\ A_{1},A_{2}\subseteq X \text{ יהיו}\\
y\in f[A_{1}]\ \text{יהי } \\
\ \ \ \ \ \ \ \ \ \ \ \ \ \  \ \ \ \ \ \ \ \downarrow \text{ה. תמונה חלקית}\\
\exists a\in A_{1}: f(a)=y\\
a \text{ נוכל לקחת את אותו ה}\downarrow A_{1}\subseteq A_{2}\\
\exists a\in A_{2}:f(a)=y\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \  \ \ \ \ \ \ \ \downarrow \text{ה. תמונה חלקית}\\
y \in  f[A_{2}]\\
\boxed{f[A_{1}]\subseteq f[A_{2}]}\text{ סה"כ }
\end{gathered}
```


2)


```math
\begin{gathered}
B_{1}\subseteq B_{2} -\text{כך ש}\ B_{1},B_{2}\subseteq Y \text{ יהיו}\\
x\in f^{-1}[B_{1}]\ \text{יהי } \\
\ \ \ \ \ \ \ \ \ \ \ \ \ \  \ \ \ \ \ \ \ \downarrow \text{ה. תמונה הפוכה}\\
f(x)\in B_{1}\\
\ \ \ \ \ \  \ \ \ \ \ \downarrow B_{1}\subseteq B_{2}\\
f(x)\in B_{2}\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \  \downarrow \text{ ה. תמונה הפוכה}\\
x \in f^{-1}[B_{2}]\\
\boxed{f^{-1}[B_{1}]\subseteq f^{-1}[B_{2}]}\text{ סה"כ }
\end{gathered}
```



# טענה
תהי $`{}f:X\to Y{}`$ פונקציה
א)תהי $`{}B\subseteq Y{}`$ אזי


```math
f[\ f^{-1}\left[ B \right]\ ]\subseteq B
```


ב)


```math
f[\ f^{-1}\left[ B \right]\ ]= B\text{ מתקיים }  B\subseteq Y \text{ לכל }\iff \text{ על }f
```


### הוכחה
תהי $`{}f:X\to Y{}`$ פונקציה
א)
תהי $`{}B\subseteq Y{}`$ 


```math
\begin{gathered}
y \in f[\ f^{-1}\left[ B \right]\ ] \text{ יהי}\\
\downarrow\\
\exists a \in f^{-1}[B]:f(a)=y\\
f(a)\in B\text{ אזי לפי ה. תמונה הפוכה } \downarrow \text{} a \in f^{-1}[B]\\
y\in B
\\
f\left[ f^{-1}\left[ B \right]  \right] \subseteq B
\text{ ולכן }
\end{gathered}
```


ב)
($`{}\impliedby{}`$)
נניח f על. תהי $`{}B\subseteq Y{}`$
($`{}\subseteq{}`$)


```math
\text{ לפי סעיף א }  f\left[ f^{-1}\left[ B \right]  \right] \subseteq B
```




```math
\begin{gathered}
b\in B \text{יהי}\\
\downarrow \text{על }f\\
\exists x \in X:f(x)\in b\\
\text{ הנ"ל מתקיים } \tilde{x}\text{ נשים לב שעבור } \\
f(\tilde{x})=b\in B\\
\tilde{x}\in f^{-1}[B]\ \text{ ולכן לפי ה. תמונה ההופכה  } \\
\exists x \in f^{-1}[B]:f(x)=b\\
\downarrow \text{ה. תמונה חלקית}\\
b\in f\left[ f^{-1}\left[ B \right]  \right] \\
f[f^{-1}[B]]=B\text{ סה"כ }
\end{gathered}
```


($`{}\supseteq{}`$)
נניח לכל $`{}b\subseteq Y{}`$ מתקיים $`{}f[f^{-1}[B]]=B{}`$ (ונוכיח f על)
בפרט עבור $`{}B=Y{}`$ נקבל


```math
\begin{gathered}
f[\underbrace{ f^{-1}[Y] }_{ \text{ שלמה}f }]=Y\\
\underbrace{ f[X] }_{ \mathrm{Im}f }=Y\text{ ולכן }
\\
\mathrm{Im}f \text{ ולכן } \\
\text{ על } f\text{ ולכן }
\end{gathered}
```



# פונקציות המכבדות יחס שקילות

### הגדרה
תהי A קבוצה ויהי R יח"ש על A
ותהי $`{}f:A\to B{}`$
נאמר שf מכבדת את R כאשר:


```math
\forall a,\tilde{a}\in A:aR \tilde{a} \implies f(A)=f(\tilde{a})
```


תהיינה A,B קבוצות. ויהי R יח"ש על A
ותהי $`{}f:A\to B{}`$ המכבדת את R
נגדיר:


```math
\begin{gathered}
\tilde{f}:A / R \underbrace{ \to }_{ \text{ע"י} } B\\
\forall[a]_{R}\in A / R : \tilde{f}([a]_{R})=f(a)\\
\text{ פונקציה }  \tilde{f} \text{ אזי}
\end{gathered}
```


## הוכחה
תהינה $`{}\tilde{f},f,R,A,B{}`$ כנ"ל

$`{}\tilde{f} {}`$ שלמה:
יהי $`{}[a]_{R}\in A / R{}`$ אזי:


```math
\begin{gathered}
\tilde{f}([a]_{R} ) = f(a) \in B\\
\ \ \ \ \ \ \ \ \  \ \ \ \ \ \  \ \ \ \ \ \ \downarrow\\
\ \ \ \ \ \ \ \ \  \ \ \ \ \ \  \ \ \ \ \ \ f:A\to B
\end{gathered}
```



$`{}\tilde{f} {}`$ ח"ע:
יהי $`{}[a]_{R}\in A / R{}`$ אזי:
נוכיח שלכל $`{}b_{1},b_{2},[a_{1}]_{R},[a_{2}]_{R} {}`$ מתקיים


```math
\tilde{f}([a_{1}]_{R}) = \tilde{f}([a_{2}]_{R}) \impliedby [a_{1}]_{R} = [a_{2}]_{R}
```


נניח $`{}[a_{1}]_{R} = [a_{2}]_{R}{}`$ כלומר $`{}a_{1}Ra_{2}{}`$ ולכן כיוון f מכבדת את R: $`{}f(a_{1})=f(a_{2}){}`$ 
כעת, לפי ה$`{}\tilde{f}{}`$


```math
\begin{gathered}
\tilde{f}([a_{1}]_{R})=f(a_{1})\\
\tilde{f}([a_{2}]_{R}) = f(a_{2})\\
\text{ שלמה וח"ע ולכן פונקציה } \tilde{f}
\end{gathered}
```
