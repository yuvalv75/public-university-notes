# כמתים

לכל: $`{}\forall{}`$
קיים:$`{}\exists{}`$

כדי שפסוק מהצורה:
$`{}\exists x: Q(x){}`$
יהיה נכון
מספיק ש1 יהיה נכון
$`{}\forall x\in \mathbb{N}:x\geq 1{}`$
המשפט הזה נכון.


מה ההופכי של הכמתים:


```math
\begin{gathered}
\neg(\forall x:Q(x))\equiv\exists x:\neg Q(x)\\ \\
\neg(\exists x:Q(x))\equiv\forall x:\neg Q(x)
\end{gathered}
```



עליכם לשלול את הפזסוק הבא:


```math
\begin{gathered}
\forall\epsilon>0\space\exists N\in \mathbb{N}\space\forall n>N: ( \frac{n+1}{n}-1)<\epsilon\\
\text{נשלול } \\
\neg(\forall\epsilon>0\space\exists N\in \mathbb{N}\space\forall n>N: ( \frac{n+1}{n}-1)<\epsilon)\equiv\\
\equiv\exists\epsilon>0\neg(\exists N\in \mathbb{N}\space\forall n>N: ( \frac{n+1}{n}-1)<\epsilon)\equiv\\
\equiv\exists\epsilon>0\space\forall N\in \mathbb{N}\neg\space\forall n>N: ( (\frac{n+1}{n}-1)<\epsilon)\equiv\\
\equiv\exists\epsilon>0\forall N\in \mathbb{N}\space\exists n>N:\neg( ( \frac{n+1}{n}-1)<\epsilon)\equiv\\
\equiv\exists\epsilon>0\forall N\in \mathbb{N}\space\exists n>N: ( \frac{n+1}{n}-1)\geq\epsilon
\end{gathered}
```



# מבוא לתורת הקבוצות

"הגדרה": קבוצה היא אוסף איברים ללא חשיבות לסדר וללא (חשיבות ל-) חזרה.
מקובל לסמן את איברי הקבוצה בין זוג סוגריים מסולסלות { }
דוגמאות:


```math
\begin{gathered}
\text{אין חשיבות לסדר וגם אין חשיבות לחזרה: }\\
\{1,2,3\}=\{1,3,2\}=\{1,1,2,3\}  \\
\{\text{חתול},\text{כוכב,*}\}\\
\{1,\{2,3\},4\} \text{ יש פה 3 איברים }\\
\{\{2,3\},\{4,2\}\}\text{ פה יש 2 איברים}\\
\{\}\text{ קבוצה ריקה }
\\\text{מקובל לסמן קבוצה ריקה בתור 0 עם קו שחוצה אותו באלכסון}
\\ \emptyset
\end{gathered}
```



ץ x שייך ל A:


```math
x\in A
```


זה אומר שx הוא אחד מאיברי הקבוצה A.



```math
\begin{gathered}
1\in\{1,2,3\}\\
4\notin\{1,2,3\}\\
1\notin\{2,\{1\}\}\\
\{1\}\in\{2,\{1\}\}
\end{gathered}
```
