## 2. סיכום ההרצאה

### נושא 1

> [!NOTE]
> **הערות והסברים**
>
>


הגדרה: תהי (A,R) קס"ח.
(1) עבור $`{}x\in A{}`$ נקרא איבר "מקסימלי" של A אם


```math
\forall a\in A: xRa\implies x=a
```


(2) עבור $`{}x\in A {}`$ נקרא "מקסימום" A אם


```math
\forall a\in A:aRx
```


(3) עבור $`{}x\in A{}`$ נקרא איבר "מינימלי" של A אם


```math
\forall a\in A: aRx\implies x=a
```


(4) עבור $`{}x\in A{}`$ נקרא "מינימום" של A אם


```math
\forall a\in A: xRa
```


אם סדרה היא סופית ויש איבר מקסימלי יחיד, אז הוא גם מקסימום.

### משפט
תהי $`{}(A,R){}`$ קס"ח ויהי $`{}x\in A{}`$. אזי
א)
 

```math
A \ \text{המקסימום היחידי של } x \impliedby A \text{ מקסימום של } x
```


 ב)
 

```math
\text{ והוא המקסימום היחיד } A-\text{מקסימלי ב}\ x \impliedby A\ \text{מקסימום של}\ x
```


 הוכחה: תהי $`{}(A,R){}`$ קס"ח, יהי $`{}x\in A{}`$ 
 א) נניח שx מקסימום של A
  נב"ש (נניח בשלילה) שקיים מקסימום נוסף נסמנו $`{}y\in A{}`$ ($`{}y\neq x{}`$) כעת, x מקסימום של A ולכן בפרט $`{}yRx{}`$.
 בנוסף, y מקסימום של A ולכן בפרט $`{}xRy{}`$ 
 מפה x=y סתירה! R יח"ש ובפרט א"ס (אנטי סימטרי)
 
ב) נניח שx מקסימום של A

>נוכיח x מקסימלי:
>יהי $`{}a\in A{}`$ כך ש $`{}xRa{}`$ 
>נתון x מקסימום ולכן בפרט נקבל ש $`{}aRx{}`$ 
>מכאן R יח"ס ובפרט א"ס =>
>ולכן a=x. ולכן x מקסימלי

> נוכיח יחידות:
> נב"ש שקיים $`{}y(\neq x)\in A{}`$ מקסימלי, x הוא מקסימום של A ולכן בפרט $`{}yRx{}`$. 
> וכיוון שy מקסימלי נקבל x=y c סתירה!


לבית:
 א)
 

```math
A \ \text{המינימופ היחידי של } x \impliedby A \text{ מינימום של } x
```


 ב)
 

```math
\text{ והוא המינימלי היחיד } A-\text{מינימלי ב}\ x \impliedby A\ \text{מינימום של}\ x
```





### הגדרה
תהי $`{}(A,R){}`$ קס"ח. ותהי $`{}B\subseteq A{}`$
(1) יש $`{}x\in A{}`$ נקרא חסם מלעיל של B אם:


```math
\forall b\in B:bRx
```


(2) יש $`{}x\in A{}`$ נקרא חסם מלרע של B אם:


```math
\forall b\in B:xRb
```


(3) יש $`{}x\in A{}`$ נקרא סופרמום/חסם עליון של B אם:
אם הוא המינימום של קבוצת חסמי המלעיל של B


```math
sup(B)
```



(4) יש $`{}x\in A{}`$ נקרא אינפימום/חסם תחתון של B אם:
אם הוא המקסימום של קבוצת חסמי המלרע של B


```math
inf(B)
```



### הגדרה
תהי A קבוצה ו-R יחס עליה. R נקרא יחס סדר מלא על A:
1. אם R הוא יס"ח
2. $`{}\forall a,b\in A:aRb\vee bRa{}`$
### טענה
יהי R יחס סדר מלא על A. ויהי $`{}x\in A{}`$ 
אזי:      x הוא מקסימום $`{}\iff{}`$ x מקסימלי.
