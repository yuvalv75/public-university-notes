# טענה
תהינה 


```math
\text{ פונקציות } \begin{cases}
f:A\to B \\
g:B\to C
\end{cases}
```


אזי:


```math
\begin{gathered}
1)\\
\text{ חח"ע } f \impliedby \text{ חח"ע } g\circ f\\
2)\\
\text{ על } g \impliedby \text{ על } g\circ f
\end{gathered}
```


### הוכחה
(1) תהינה $`{}f:A\to B{}`$ , $`{}g:B\to C{}`$ פונקציות
נניח $`{}g\circ f{}`$ חח"ע
ונוכיח $`{}f{}`$ חח"ע
יהיו $`{}a_{1},a_{2}\in A{}`$ כך ש-


```math
\begin{gathered}
f(a_{1})=f(a_{2})\\
g\ \text{נפעיל}\downarrow\\
g(f(a_{1}))=g(f(a_{2}))\\ \downarrow\\
(g\circ f)(a_{1})=(g\circ f)(a_{2})\\ \text{חח"ע }g\circ f\downarrow\\
a_{1}=a_{2}\\ \\
\text{ חח"ע } f \text{ ולכן}
\end{gathered}
```



(2) תהינה $`{}f:A\to B{}`$ , $`{}g:B\to C{}`$ פונקציות
נניח $`{}g\circ f{}`$ על, ונוכיח g על
יהי $`{}c\in C{}`$ 


```math
\begin{gathered}
\text{ נתון על. ולכן בפרט } g\circ f:A\to C\\
a\in A\text{ הנ"ל קיים } c\text{ גם עבור } \\
(g\circ f)(a)=c \text{כך ש } \\
b:=f(a)\text{ נגדיר}\\
g(b)=g(f(a))=(g\circ f)(a)=c\text{ כעת }
\end{gathered}
```


מצאנו $`{}b\in B{}`$ כך ש- $`{}g(b)=c{}`$ ולכן g על. מש"ל.

### הוכחה
תהינה 


```math
\text{ פונקציות } \begin{cases}
f:A\to B \\
g:B\to C
\end{cases}
```


(1) נניח $`{}g,f{}`$ חח"ע
ונוכיח $`{}g\circ f{}`$ חח"ע
יהיו $`{}a_{1},a_{2}\in A{}`$ כך ש-


```math
\begin{gathered}
(g\circ f)(a_{1})=(g\circ f)(a_{2})\\ \downarrow \text{ה. הרכבה}\\
g(f(a_{1}))=g(f(a_{2}))\\ \downarrow \text{חח"ע } g\\
f(a_{1})=f(a_{2})\\ \downarrow \text{חח"ע } f\\
a_{1}=a_{2}\\
\boxed{\text{ חח"ע } g\circ f \ \text{סה"כ}}
\end{gathered}
```



(2) נניח $`{}g,f{}`$ על
ונוכיח $`{}g\circ f{}`$ על
יהי $`{}c\in C{}`$ 


```math
\begin{gathered}
\text{ הנ"ל } c\text{ על ולכן בפרט עבור } g:B\to C\\
g(b)=c\text{ כך ש } \tilde{b}\in B\text{ קיים } \\
\text{ בנוסף } \\
b \text{ על ולכן בפרט עבור } g:A\to B\\
f(a)=b -\text{כך ש}\ a\in A\text{ קיים}\\
(g\circ f)(a)=g=g(f(a))=g(b)=c\text{ כעת, מתקיים }\\
(g\circ f)(a)=c  -\text{כך ש}\ a\in A\text{ קיים}\text{ ולכן}\\
\text{ על } g\circ f \text{ ולכן }
\end{gathered}
```

### טענה
תהיינה $`{}A,B{}`$ קבוצות סופיות
אזי


```math
\begin{cases}
\text{ קיימת פונק' חח"ע }  \\
f:A\to B
\end{cases} \iff \left| A \right|\leq \left| B \right|
```


### הוכחה
תהיינה $`{}A,B{}`$ קבוצות סופיות
נחלק למקרים:
1)
$`{}A=\emptyset{}`$
ניקח את f להיות היחס הריק.
היא אכן ח"ע וגם חח"ע (באופן ריק), וכיוון ש$`{}A=\emptyset{}`$ אזי הוא שלם.
סה"כ f פונק' חח"ע
2)
אז $`{}\impliedby{}`$ נניח $`{}\left| A \right|\leq \left| B \right|{}`$
נסמן $`{}A=\left\{ \overbrace{ a_{1},\dots a_{n }^{ \text{שונים} }} \right\}{}`$, נסמן $`{}B=\left\{ \overbrace{ b_{1},\dots b_{n} }^{ \text{שונים} } \right\}{}`$ 


```math
\begin{gathered}
f:A\to B\text{ נגדיר } \\
1\leq i\leq n\\
\forall a_{i}\in A:f(a_{i}=bi)\\
'\text{ פונק } f\begin{cases}
(n\leq m \text{ כי})\text{שלמה} \ f \ \text{אכן} \\
a_{i}\mapsto b_{i}\text{ ח"ע}
\end{cases}\\
(1\leq i,j\leq n)a_{i},a_{j}\in A\text{ יהיו } :\text{ חח"ע }  f\ \text{נראה } \\
f(a_{i})=f(a_{j})\text{ כך ש } \\
\downarrow f\text{.ה}\\
b_{i}=b_{j}\\
\downarrow \\
i=j \\ \downarrow\\
a_{i}=a_{j}
\end{gathered}
```


$`{}\implies{}`$
נניח שקיימת $`{}f:A\to B{}`$ חח"ע
נחלק למקרים
1)
$`{}A=\emptyset{}`$
$`{}\left| A \right|\leq \left| B \right|{}`$
2)


```math
\begin{gathered}
A=\left\{ \overbrace{ a_{1},\dots a_{n} }^{ \text{שונים} } \right\} \text{נסמן} :A\neq \emptyset\\
\left\{ f(a_{1}),\dots,a(a_{n}) \right\} \subseteq B\\
\text{ חח"ע והרי } f,\text{ איברים שונים } n\text{ יש } \\
a_{1},\dots a_{n}\\
\text{ שונים }
\end{gathered}
```
