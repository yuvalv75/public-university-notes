```math
\begin{gathered}
[a]_{R}:=\{b\in A:(a,b)\in R\}\\
A/R:=\{[a]_{R} \ |\ a\in A\}
\end{gathered}
```



### טענה
תהי R יחס שקילות (יח"ש) על קבוצה A


```math
(a,b)\in \mathbb{R}\to aRb
```


ויהיו $`{}x,y\in A{}`$ אזי.


```math
x\in[y]_{R} \iff [x]_{R}=[y]_{R}
```


הוכחה:


```math
\begin{gathered}
x,y\in A\text{ ויהיו } A\text{ יח"ש על הקבוצה } R\text{יהי } \\
(x\in[y]_{R}\text{ונוכיח})\ [x]_{R}=[y]_{R}\text{נניח } \impliedby\\
(x,x)\in \mathbb{R}\text{ הוא רפלקסיבי ולכן בפרט } R\\
x\in[x]_{R}\text{ולכן } \\
[x]_{R}=[y]_{R}\text{ נתון } \downarrow\\
\boxed{x\in[y]_{R}}\\ \\
(\text{ בעזרת הכלה דו כיוונית }[x]_{R}=[y]_{R}\ \text{ונוכיח})x\in[y]_{R}\text{ נניח } \implies\\
z\in[y]_{R}\text{ יהי } \supseteq\\
\downarrow \text{ה. מחלקת שקילות}\\
(y,z)\in R\\ \downarrow \text{ יח"ש ובפרט סימטרי }R\text{ וכיוון ש }(y,x)\in R\text{כלומר}x\in[y]_{R}\text{נתון} \\
\text{אזי }
\\(x,z)\in R\\ (x,y),(y,z)\in R\text{הראינו כי}\downarrow \text{ה.מחלקת שקילות} \\ z\in[x]_{R}\\ \\
z\in[x]_{R}\text{ יהי } \subseteq\\
\downarrow \text{ה. מחלקת שקילות}\\
(x,z)\in R\\ (y,x)\in R\text{ ולכן }x\in[y]_{R}\text{נתון}\\ '\text{יח"ש ובפרט טרנז}R \downarrow\\
(y,z)\in R \\ \downarrow \text{ה. מחלקת שקילות} \\ z\in[y]_{R}\\ \\
\boxed{[x]_{R}=[y]_{R}\text{סה"כ הראינו } }
\end{gathered}
```


### טענה
יהי R יח"ש על קבוצה A
ויהיו $`{}x,y\in A{}`$
אזי


```math
[x]_{R} \cap[y]_{R}=\emptyset\vee [x]_{R}=[y]_{R}
```


הוכחה:
תהי R יח"ש על A. ויהיו $`{}x,y\in A{}`$
נחלק למקרים:


```math
\begin{gathered}
1) [x]_{R}=[y]_{R}\\ \\ 2)[x]_{R}\neq[y]
\end{gathered}
```


אם 1 נכון אז סיימנו,
אם 2 קורה אז נרצה להוכיח $`{}[x]_{R} \cap[y]_{R}=\emptyset{}`$ 
נניח בשלילה שקיים $`{}z\in[x]_{R} \cap[y]_{R}{}`$


```math
\begin{gathered}
z\in[y]_{R}\land z\in[x]_{R}\\ \downarrow \text{טענה קודמת}\\
[z]_{R}=[x_{R}]\land [z]_{R}=[y]_{R}\\
\text{ סתירה! } [x]_{R}=[y]_{R}\ \text{ולכן } \\
\text{זרות } [x]_{R},[y]_{R}\text{ולכן קיבלנו } \\
\text{סה"כ הראנו מקרה שבכל מקרה }
\text{הן } [x]_{R},[y]_{R}\\ \boxed{\text{זרות או שוות}}
\end{gathered}
```



### משפט
יהי R יח"ש על קבוצה A
אזי:
1) לכל $`{}[a]_{R}\in A/R{}`$ מתקיים $`{}[a]_{R}\neq 0{}`$
2) לכל $`{}[a]_{R},[b]_{R}\in A/R{}`$ מתקיים שהן זרות או שוות
3) ש


```math
\bigcup_{[a]_{R}\in A/R}[a]_{R}=A
```


### הוכחה:
יהי R יח"ש על  A
1) תהי $`{}[a]_{R}\in A/R{}`$ 


```math
[a]_{R}\neq \emptyset\text{ יח"ש ובפרט רפלקסיבי ולכן } R
```


2) הוכחנו עמוד קודם
3) נוכיח זאת ע"י הכלה דו כיוונית.
4) 
   

```math
\begin{gathered}
\subseteq \\
   x\in\bigcup_{[a]_{R}\in A/R}[a]_{R}\ \text{יהי } \\
   \text{ה.איחוד } \downarrow \\
   \exists [a]_{R}\in A/R : x\in[a]_{R}
   \\ \downarrow \text{ה. מחלקת שקילות}\\ [a]_{R}=\{b\in A|(a,b)\in A\}\\ [a]_{R}\subseteq A\\x\in A \\ \\ \supseteq
  x\in A \text{יהי }
  (x,x)\in R\text{רפלקסיבי ולכן } R\\ x\in[x]_{R}\text{כלומר}\\
  \text{ולכן בפרט שייך לאיחוד מחלוקות השקילות (ה.איחוד): כלומר } \\
  x\in\bigcup_{[a]_{R}\in A/R}[a]_{R}
\end{gathered}
```



# הגדרה:
תהי A קבוצה משפחה של קבוצות $`{}\{A_{i}\}_{i\in I}{}`$ נקראת חלוקה של A כאשר:


```math
\begin{gathered}
1) A_{i}\neq \emptyset \text{ מתקיים} i\in I\ \text{לכל}\\
   2) \text{שונים מתקיים}\ i,j\in I\text{לכל}\\ \text{זרות}A_{i},A_{j}\\
      3) \bigcup_{i\in I}A_{i}=A
\end{gathered}
```



מסקנה: יהי R יח"ש על A אזי A/R היא חלוקה של A

# משפט
תהי A קבוצה
ותהי $`{}\{A_{i}\}_{i\in I}{}`$ חלוקה של A
נגדיר את היחס המושרה מהחלוקה:


```math
\begin{gathered}
R:=\{(a,b)|\begin{array}{}
\exists i\in I: \\
a\in A_{i}\land b\in A_{i}
\end{array}\}\\ \\
1) A \text{ הנ"ל הוא יח"ש על }R\\
   2) \text{ הנל} \ R\ \text{עבור}\\
      A/R=\bigcup_{i\in I}A_{i}
\end{gathered}
```
