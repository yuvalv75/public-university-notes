# יחסי סדר
הגדרה: תהי A קבוצה ויהי R יחס עליה
נאמר ש-R הוא אנטי סימטרי כאשר:


```math
\begin{gathered}
\forall a,b \in A: \overbrace{ (aRb) }^{ (a,b)\in R }\land \left( bRa \right) \implies a=b\\
\end{gathered}
```


הגדרה: יחס R על A נקרא יחס סדר חלקי על A כאשר R רפלקסיבי, אנטי סימטרי וטרנזיטיבי.


```math
\left[ \begin{array}{c}
A\overbrace{ \text{ יחס סדר חלקי על } }^{ \text{יס"ק} } R \\
\underbrace{ \text{ קבוצה סדורה חלקית } }_{ \text{קס"ח} } \left( A,R \right)
\end{array} \right]
```
