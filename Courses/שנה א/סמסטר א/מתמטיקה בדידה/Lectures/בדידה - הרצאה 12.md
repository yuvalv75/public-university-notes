פונקציית הזהות:


```math
\begin{gathered}
f:A\to A\\
f(a)=a
\end{gathered}
```


פונק' ההכלה:


```math
\begin{gathered}
A\subseteq B\\
f:A\to B\\
f(n)=n
\end{gathered}
```


![Pasted image 20261123093720](../../../../../Pasted%20image%2020261123093720.png)
### טענה
תהיינה A,B קבוצות 
ותהי $`{}f:A\to B{}`$ פונק'
אזי


```math
g_{1}=g_{2} :\text{ מההגדרה לעיל } g_{1},g_{2}\text{ עבור } \impliedby\text{ הפיכה } f
```


### הוכחה
תהי: $`{}f:A\to B{}`$ פונק' הפיכה
אזי קיימות $`{}g_{1},g_{2}:B\to A{}`$ פונק'
כך ש:


```math
\begin{cases}
g_{1}\circ f=Id_{A} \\
f\circ g_{2}=Id_{B}
\end{cases}
```


נוכיח $`{}g_{1}=g_{2}{}`$ :אכן $`{}g_{1},g_{2}:B\to A{}`$ 
בנוסף יהי $`{}b\in B{}`$ 


```math
\begin{gathered}
g_{1}(b)\overbrace{ = }^{ f\circ g_{2}=Id_{B} }g_{1}((f\circ g_{2})(b))=(g_{1}\circ f\circ g_{2})(b)\\
\overbrace{ = }^{ \text{הרכבה אסוציאטיבית} } = ((g_{1}\circ f)\circ g_{2})(b)= (g_{1}\circ f)(g_{2}(b))\overbrace{ = }^{ g_{1}\circ f=Id_{A} }=g_{2}(b)\\
g_{1}=g_{2}\impliedby
\end{gathered}
```



### מסקנה
תהי: $`{}f:A\to B{}`$ פונק' הפיכה
אזי קיימות $`{}g_{1},g_{2}:B\to A{}`$ פונק'
אזי


```math
\begin{cases}
g_{1}\circ f=Id_{A} \\
f\circ g_{2}=Id_{B}
\end{cases}\text{ פונקציה כך ש } g:B\to A\text{ קיימת } \iff\text{ הפיכה } f
```
