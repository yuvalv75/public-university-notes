### אינדוקציה - המשך
דוגמא :
יש n אנשים בחדר וכל 2 אנשים לוחצים ידיים בדיוק פעם אחת
הוכיחו שמספר לחיצות הידיים שבוצעו בחדר הוא $`{}\frac{n(n-1)}{2}{}`$
פתרון:
נוכיח באינד' על n=1
בסיס n=1:
כלומר יש אדם אחד בחדר ולכן בוצעו 0 לחיצות ידיים ואכן $`{}\frac{1(1-1)}{2}=0{}`$

* צעד: נניח שהטענה נכונה ל-n טבעי כלשהו ונוכיח אותה עבור n+1

יש n+1 אנשים בחדר.
ניקח אחד מהם נסמנו $`{}\bar x{}`$ או דני (עדיף דני)
נשים 3>:


```math
\text{מס לחיצות הידיים בחדר } = \text{מס' לחיצות הידיים שדני לא שותף בהם} + \text{מס' לחציות הידיים להן דני שותף}
```



לפי הנחת האינדוקציה $`{}\text{מס' לחיצות הידיים שדני לא שותף בהם}{}`$ הוא $`{}\frac{n(n-1)}{2}{}`$
ו$`{}\text{מס' לחציות הידיים להן דני שותף}{}`$ שווה לn
החיבור שווה ל$`{}\frac{n(n-1)}{2}+n{}`$


```math
\frac{n(n-1)}{2}+n= n\left( \frac{n-1}{2}+1 \right)=\frac{(n+1)n}{2}
```


### הכללה 1:
תהי $`{}P(n){}`$  טענה על המספרים הטבעיים ויהי $`{}k\in \mathbb{N}{}`$ 
ונניח ש - (1)    $`{}P(k)=T{}`$
וגם כי -   (2)     $`{}\forall k\leq n\in \mathbb{N}:P(n)\implies P(n+1){}`$
אזי $`{}P(n){}`$ נכונה לכל: n טבעי $`{}\leq{}`$ k

הוכיחו כי הטענה הבאה נכונה לכל $`{}2\leq n{}`$ טבעי
$`{}n!<n^n{}`$
פתרון: נוכיח באינדוקציה על n
בסיס 2=n
2!<2^2

צעד: נניח שהטענה נכונה ל-n טבעי $`{}\leq{}`$ 2 כלשהו ונוכיח ל- n+1


```math
\begin{gathered}
(n+1)! = n!(n+1)\overbrace{ < }^{ \text{ה. אינדוקציה} } n^n (n+1)<(n+1)^{n}(n+1)=(n+1)^{(n+1)}\\
\\
(n+1)!<(n+1)^{(n+1)}\\
\text{ טבעי } 2<n\text{לכן הטענה נכונה לכל }
\end{gathered}
```



### הכללה 2

נוכיח שלכל מס' טבעי $`{}2\leq{}`$ מתקיים שניתן לכתוב אותו כמכפלת מספרים ראשוניים
$`{}P(1)=T{}`$                                                                           (1) נניח ש
$`{}(\forall k\leq n \ \ \ P(k))\implies P(n+1){}`$                                          (2)

הנחת האינדוקציה: P(n) נכון

בסיס:  $`{}n=2{}`$
אכן 2=2 ו2 בעצמו הוא ראשוני
צעד:
נניח שהטענה נכונה מ-2 עד n כולל ($`{}n{}`$ טבעי) ונוכיח שהיא נכונה ל- n+1 .

* נחלק למקרים:
(1) n+1 ראשוני
(2) n+1 לא ראשוני

* לפי 1:
מכפלה של אחד ראשוני:
n+1 = n+1

* לפי 2:
 קיימים $`{}1< k,t<n+1{}`$ כך ש-
 

```math
n+1 = k\cdot t
```


אז $`{}2\leq k\leq n{}`$ ולכן לפי הנחת האינדוקציה שווה למכפלת ראשונים.
אז $`{}2\leq t\leq n{}`$ ולכן לפי הנחת האינדוקציה שווה למכפלת ראשונים.
ולכן הטענה נכונה לכל $`{}2\leq n\in \mathbb{N}{}`$



דוג':
הוכיחו כי לכל $`{}n\in \mathbb{N}{}`$ ולכל $`{}A, \dots , A_{n}{}`$ קבוצות מתקיים ש


```math
A,\Delta\dots\Delta A_{n} = \{x|A,\Delta\dots\Delta A_{n} \ \text{נמצא במס' אי זוגי מהקבוצות }x\}
```


נוכיח באינדוקציה על n
n=1
$`{}A_{1}=\{x|A_{1} \ \text{נמצא במס' אי זוגי מהקבוצות }x\}{}`$

צעד:
נניח שהטענה נכונה לn ונוכיח ל-n+1
תהינה $`{}A_{1},\dots,A_{n}{}`$ קבוצות


```math
\begin{gathered}
A,\Delta\dots\Delta A_{n+1} \overbrace{ = }^{\Delta \text{אסוצ} } (A_{1}\Delta\dots A_{n})\Delta A_{n+1} \overbrace{ = }^{ \text{ה. האינדוקציה} } \{x|A,\Delta\dots\Delta A_{n+1} \ \text{נמצא במס' אי זוגי מהקבוצות }x\}\Delta A_{n+1}\\ \\
\{x|x\notin A_{n+1}\text{ וגם }A,\Delta\dots\Delta A_{n} \ \text{נמצא במס' אי זוגי מהקבוצות }x\}\cup \\
\cup \{x|x\in A_{n+1}\text{ וגם }A,\Delta\dots\Delta A_{n} \ \text{נמצא במס' זוגי מהקבוצות }x\}=\\ \\=
\{x|x\notin A_{n+1} \text{ וגם }A,\Delta\dots\Delta A_{n+1}\text{נמצאים במספר אי זוגי מהקבוצות}\}\cup\\ \cup
\{x|x\in A_{n+1} \text{ וגם }A,\Delta\dots\Delta A_{n+1}\text{נמצאים במספר אי זוגי מהקבוצות}\}=\\ \\=
\{x|A_{1},\dots A_{n+1}\text{שנמצאים מספר אי זוגי מהקבוצות}\}
\\ \\
\boxed{\{x|A,\Delta\dots\Delta A_{n+1} \ \text{נמצא במס' אי זוגי מהקבוצות }x\}}
\end{gathered}
```
