# יחסים



הגדרה:
תהינה A,B קבוצות.
נגדיר את המכפלה הקרטזית


```math
\begin{gathered}
A\times B:=\{(a,b) | a\in A, b\in B\}\\ A=\{1,2\}, B=\{3,4\}\\ \\
A \times B=\{(1,3),(1,4),(2,3),(2,4)\}\\
B\times A=\{(3,1),(3,2),(4,1),(4,2)\}
\end{gathered}
```


נשים לב: $`{}A\times B\neq B\times A{}`$ 
### תכונות בסיסיות


```math
\begin{gathered}
1)\\
A\times \emptyset\overbrace{ = }^{ \text{א} }\emptyset\overbrace{ = }^{ ב }\emptyset \times A\\ \\
2)\\
A\times(B\cap C)=(A\times B)\cap(A\times C)\\ \\
3)\\
A\times*(B\cup C)=(A\times B)\cup(A\times C)\\ \\
4)\\
(A\times B)\cap(C\times D)=(A\cap C)\times(B\cap D)\\ \\
5)\\
(A\times B)\cup(C\times D) \subseteq (A\cup C)\times(B\cup D)\\
\end{gathered}
```


הוכחה:
תהינה A,B,C קבוצות.


```math
\begin{gathered}
1.א) \\ \text{צל}\\
A\times \emptyset=\emptyset\\
(a,b)\in A\times \emptyset \ \text{יהי } \\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \downarrow \text{ה. מכפלה הקרטזית}\\
(a\in A)\land(b\in \emptyset)\\ \downarrow \text{בפרט}\\
!\text{ סתירה } b\in \emptyset
\end{gathered}
```


לעשות ב בבית
הוכחה ל2:
יהי


```math
\begin{gathered}
(x,y)\in A\times (B\cap C)\\
\iff\text{ה. מכפלה קרטזית}\\
(x\in A)\land(y\in B\cap C)\\ \iff \\
(x\in A)\land [(y\in B)\land(y\in C)]\\
(x\in A)\land(x\in A)\land [(y\in B)\land(y\in C)]\\ \iff\text{קומו+אסוצ}\\
[(x\in A)\land(y\in B)]\land[(x\in A)\land(y\in C)] \\ \iff \text{ה. מכפלה קרטזית}\\
((x,y)\in A\times B)\land((x,y)\in A\times C)
\\ \iff \text{ה.חיתוך}\\
\boxed{(x,y)\in (A\times B)\cap( A\times C)}
\end{gathered}
```



<u>הגדרה:</u>
תהינה A,B קבוצות.


```math
\begin{gathered}
B-\text{ ל } A\text{ נקרא יחס מ } R\subseteq A\times B \\
\text{ זה נקרא היחד המלא } R=A\times B \ \ \ \text{:מינוח}\\
\text{ זה נקרא היחס הריק } R=\emptyset
\end{gathered}
```



### יחסי שקילות
הגדרה:
תהי A קבוצות. יחס $`{}R\subseteq A\times A{}`$ נקרא יחס שקילות על A כאשר:


```math
\begin{gathered}
\text{ רפלקסיבי } R \ \ (1\\
\text{ סימטרי } R \ \ (2\\
\text{ טרנזיטיבי } R \ \ (3
\end{gathered}
```



הגדרה:
תהי A קבוצה ויהי R יחס על A
1) נאמר שR הוא רפלקסיבי כאשר $`{}\forall a\in A: (a,a) \in R{}`$ 
2) נאמר ש-R הוא סימטרי כאשר: $`{}\forall a,b\in A: (a,b)\in R \implies (b,a)\in R{}`$
3) נאמר שR הוא טרנזיטיבי כאשר:


```math
\forall a,b,c\in A: [(a,b)\in R]\land[(b,c)\in R]\implies[(a,b)\in R]
```





```math
\begin{gathered}
A \ \text{יחס הזהות על }  R=\{(a,a)|a\in A\}\\
\text{היחס המלא } R= A\times A\\
R=\{(1,1),(2,2),(3,3),(2,1),(1,2)\}
\end{gathered}
```




דוגמא: נגדיר יחס על $`{}\mathbb{Z}{}`$ באופן הבא:


```math
\begin{gathered}
(a,b)\in R\iff 3\mid a-b\\ \left( \frac{a-b}{3}\in \mathbb{Z} \right)\\
\end{gathered}
```


נוכיח שזהו יח"ש על $`{}\mathbb{Z}{}`$ :
רפלקסיבי: יהי $`{}a\in \mathbb{Z}{}`$ 


```math
\begin{gathered}
3\mid\overbrace{ (a-a) }^{ 0 } -\text{נשים לב ש}\\ \downarrow R.ה\\
(a,a)\in \mathbb{R}
\end{gathered}
```


סימטרי: יהיו $`{}a,b\in \mathbb{Z}{}`$ כך ש- $`{}(a,b)\in \mathbb{R}{}`$


```math
\begin{gathered}
\downarrow R.ה\\
3\mid a-b\\ \downarrow \text{כלומר}\\
\frac{a-b}{3}\in \mathbb{Z}
\downarrow \boxed{\frac{a-b}{3}=-\frac{b-a}{3}}  \text{כי}\\
\frac{b-a}{3}\in \mathbb{Z}
\downarrow \\
3\mid b-a\\
\downarrow R.ה\\
(b,a)\in R
\end{gathered}
```



טרנזיטיביות: יהי $`{}a,b,c\in \mathbb{Z}{}`$ כך ש-


```math
\begin{gathered}
(a,b)\in R\land(b,c)\in R\\
\downarrow R.ה\\
\left( \frac{a-b}{3}\in \mathbb{Z} \right)\land\left( \frac{b-c}{3}\in \mathbb{Z} \right)\\ \downarrow\\
\frac{a-c}{3}=\frac{a-b}{3}+\frac{b-c}{3}\in \mathbb{Z} \\ \downarrow \\
(a,c)\in R\\
\mathbb{Z}\text{ על } \text{ יח"ש } R\ \text{ולכם סה"כ }
\end{gathered}
```



הגדרה: תהי A קבוצה ויהי R יח"ש על A
יהי $`{}a\in A{}`$ 
נגדיר:


```math
\begin{gathered}
1)\\
a\text{מחלקת השקילות של } [a]_{R}:=\{b\in A \mid(a,b)\in R \} \\ \text{בעצם מי בני הזוג שלו}\\ \\
2)\\
\text{קבוצת המנה } A/R:=\{[a]_{R}|a\in A\}\\ \text{מחלקות השקילות נכנסות בתור איברים}
\end{gathered}
```
