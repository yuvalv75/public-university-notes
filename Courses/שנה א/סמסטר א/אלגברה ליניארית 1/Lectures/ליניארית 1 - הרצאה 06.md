### טענה
יהי $`{}V{}`$  מ"ו ותהינה $`{}A,B\subseteq V{}`$ 
אזי $`{}spA+spB=sp(A\cup B){}`$ 
### הוכחה
יהי $`{}V{}`$ מ"ו ותהינה  $`{}A,B\subseteq V{}`$ 
נחלק למקרים:
1)


```math
\begin{gathered}
A=\emptyset \lor B=\emptyset\\
\text{ לעשות בבית }
\end{gathered}
```


2)


```math
\begin{gathered}
A,B\neq \emptyset\\
\subseteq\\
v\in spA+spB\ \text{יהי } \\
:w\in spB,u\in spA\text{ כלומר קיימים} \\
v=u+w\\
u=\sum^n_{i=1}\alpha_{i}\vec{a_{i}}\text{כך ש } \begin{array}{}
\vec{a_{1}},\dots,\vec{a_{n}}\in A \\
\alpha_{1},\dots,\alpha_{n}\in \mathbb{F}
\end{array}\text{ כלומר קיימים}\ \  u\in spA\\
w=\sum^n_{i=1}\beta_{i}\vec{b_{i}}\text{כך ש } \begin{array}{}
\vec{b_{1}},\dots,\vec{b_{n}}\in B \\
\beta_{1},\dots,\beta_{n}\in \mathbb{F}
\end{array}\text{ כלומר קיימים}\ \  w\in spA\\
\text{ קיבלנו } \\
v=u+w=\\
=\underbrace{ \alpha_{1}+\vec{a_{1}} }_{ \in A\subseteq A\cup B }+\dots+\underbrace{ \alpha_{n}\vec{a_{n}} }_{ \in A\subseteq A\cup B }+\underbrace{ \beta_{1}\vec{b_{1}} }_{ \in B\subseteq A\cup B }+\dots+\underbrace{ \beta_{n}\vec{b_{n}} }_{ \in B\subseteq A\cup B }\to v\in sp(A\cup B)
\end{gathered}
```




```math
\begin{gathered}
\supseteq\\
v\in sp(A\cup B)\\ \downarrow\\
-\text{ כך ש } \begin{array}{}
v_{1},\dots,v_{n}\in A\cup B \\
\alpha_{1},\dots,\alpha_{n}\in \mathbb{F}
\end{array}\text{ קיימים }\\
v=\alpha_{1}+v_{1}+\dots+\alpha_{n}v_{n} \\
-\text{ כך ש } 1\leq k\leq n-1\text{ בה"כ נניח שקיים } \\
v_{1},\dots v_{n}\in A, v_{k+1},\dots v_{n}\in B\\
\left[ \begin{array}{}
\text{ אחרת, נשתמש בקומ' בחיבור במ"ו }  \\
B\text{ כולם מ } \setminus A-\text{ כולם מ } v_{1},\dots,v_{n}\text{ אם } (*)\ \text{בבית}
\end{array} \right]
\end{gathered}
```




# תלות ליניארית
### הגדרה
יהי $`{}V{}`$ מ"ו מעל $`{}\mathbb{F}{}`$ . ותהי $`{}S\subseteq V{}`$ קבוצה.
(1) נאמר ש-$`{}S{}`$ תלויה ליניארית (ת"ל) כאשר:


```math
\begin{gathered}
-\text{לא כולם 0 כך ש}\begin{array}{}
s_{1},\dots s_{n}\in S \\
\alpha_{1},\dots\alpha_{n}\in \mathbb{F}
\end{array} \text{קיימים} \\
\end{gathered}
```


(2) נאמר ש $`{}S{}`$ בלתי תלויה ליניארית כאשר $`{}S{}`$ לא ת"ל. כלומר:
לכל $`{}s_{1},\dots s_{n}\in S{}`$ שונות ולכל $`{}\alpha_{1},\dots,\alpha_{n}\in \mathbb{F}{}`$  המקיימים


```math
\begin{gathered}
\alpha_{1}+s_{1}+\dots+\alpha_{n}a_{n}=0\\
\alpha_{1}=\dots=\alpha_{n}=0\text{ מתקיים }
\end{gathered}
```

### משפט
יהי $`{}V{}`$ מ"ו מעל $`{}\mathbb{F}{}`$ ותהי $`{}A\subseteq V{}`$ 
אזי הבאים שקולים:
(1) A ת"ל
(2) קיים $`{}v\in A{}`$ כך ש-$`{}v\in sp(A\setminus \left\{ v \right\} ){}`$ 
(3) קיים $`{}v\in A{}`$ כך ש- $`{}sp(A\setminus \left\{ v \right\})=spA{}`$ 
### הוכחה
יהי $`{}V{}`$ מ"ו מעל $`{}\mathbb{F}{}`$ 
נוכיח (1) -> (2) -> (3) -> (1)
$`{}I:{}`$
> צ"ל: (1)->(2)

נניח A ת"ל ולכן קיימים:


```math
\begin{array}{}
\text{ שונים } v_{1},\dots,v_{n}\in A \\
0\text{ לא כולם } \alpha_{1},\dots\alpha_{n}\in \mathbb{F}
\end{array}
```


כך ש-


```math
\alpha v_{1}+\dots+\alpha_{n}v_{n}=0
```


ב"הכ נניח $`{}\alpha_{1}\neq 0{}`$ (אחרת משתמש בקומו' בחיבור במ"ו)


```math
\begin{gathered}
\alpha_{1}v_{1}=-\alpha_{2}v_{2}-\dots-\alpha_{n}v_{n} \ \ \ /\cdot(\alpha_{1})^{-1}\\ \downarrow\\
v_{1}=-\frac{\alpha_{2}}{\alpha_{1}}\boxed{v_{2}}-\dots-\frac{\alpha_{n}}{\alpha_{1}}\boxed{v_{n}}\\ \downarrow\\
v_{1}\in sp(A\setminus \left\{ v_{1} \right\} )
\end{gathered}
```




> נראה ש(2)->(3): נניח שקיים $`{}\tilde{v}\in A{}`$ כך ש- $`{}\tilde{v}\in sp(A\setminus \left\{ \tilde{v} \right\}){}`$

נוכיח שעבור $`{}\tilde{v} {}`$ הנ"ל $`{}sp(A\setminus \left\{ \tilde{v} \right\}){}`$ 


```math
\begin{gathered}
\subseteq\\
sp(A\setminus \left\{ \tilde{v} \right\} )\subseteq spA\impliedby A\setminus \left\{ \tilde{v} \right\} \subseteq A \\ \downarrow \\
A\subseteq B\implies spA\subseteq spB \\ \\ \supseteq
\end{gathered}
```


 יהי $`{}u\in spA{}`$ 
 

```math
\begin{gathered}
\downarrow \\
 \text{ שונים } a_{1},\dots a_{n}\text{ נניח } \exists\begin{array}{}
 \vec{a_{1}},\dots,\vec{a_{n}}\in A \\
 \alpha_{1},\dots\alpha_{n}\in \mathbb{F}
\end{array}:
u=\alpha_{1}\vec{a_{1}}+\dots+\alpha_{n}\vec{a_{n}}\\
\text{ נחלק למקרים } \\
\text{ אזי } \vec{a_{1}},\dots, \vec{a_{n}}\neq \vec{v}\ \text{אם } (*)\\
\vec{a_{1}},\dots, \vec{a_{n}}\in A
u\in sp(A\setminus \left\{ \vec{v} \right\} )\text{ וקיבלנו}
\end{gathered}
```
