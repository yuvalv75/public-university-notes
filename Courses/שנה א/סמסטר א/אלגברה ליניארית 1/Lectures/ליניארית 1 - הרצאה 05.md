# צירופים ליניאריים והמרחב הנפרש
הגדרה: יהי $`{}\mathrm{V} {}`$ מ"ו מעל שדה $`{}\mathbb{F}{}`$ . ותהי $`{}\mathrm{S}\subseteq \mathrm{V}{}`$ ת"ק 
ויהי  $`{}v\in \mathrm{V}{}`$ הוא צ"ל של $`{}\mathrm{S} {}`$ אם קיימים $`{}\vec{s_{1}},\dots ,\vec{s_{n}}\in \mathrm{S}{}`$ כך ש- 


```math
\begin{gathered}
\alpha_{1},\dots,\alpha_{n}\in \mathbb{F}\\
v=\alpha_{1}\vec{s_{1}}+\dots + \alpha_{n}\vec{s_{n}}
\end{gathered}
```


הגדרה: יהי $`{}\mathrm{V }{}`$ מרחב וקטורי מעל שדה $`{}\mathbb{F}{}`$, ותהי $`{}\mathrm{S}\subseteq \mathrm{V}{}`$ 
נגדיר את $`{}\underbrace{ sp(\mathrm{S}) }_{ span(\mathrm{S}) }{}`$ (המרחב הנפרש ע"י $`{}\mathrm{S}{}`$) :
אם $`{}sp(\mathrm{S})=\emptyset{}`$ נגדיר $`{}sp(\mathrm{S}):=\left\{ \emptyset \right\}{}`$


```math
\begin{gathered}
sp(\mathrm{S}):=\left\{ \alpha_{1}s_{1}+\dots+\alpha_{n}+s_{n}\middle| \begin{array}{c}
n\in \mathbb{N} \\
s_{1},\dots,s_{n\in \mathrm{S}} \\
\alpha_{1},\dots,\alpha_{n}\in \mathbb{F}
\end{array} \right\} :\text{אז} \ \mathrm{S} \neq \emptyset \ \text{אם}\\
\end{gathered}
```


![Pasted image 20261109130028](../../../../../Pasted%20image%2020261109130028.png)
דוגמה:


```math
1+2x\in sp\left\{ 1+x+x^{2},1+x,2x^{2} \right\} \mathrm{V}=\mathbb{R}_{2}\left[ x \right]
```


פתרון: נסדוק האם קיימים $`{}\alpha,\beta,\gamma\in \mathbb{R}{}`$ כך ש-


```math
\begin{gathered}
\alpha(1+x+x^{2})+\beta(1+x)+\gamma(2x^{2})=1+2x\\
(\alpha+\beta)+(\alpha+\beta)x+(\alpha+2\gamma)x^{2}=1+2x\\
\text{ השוואת מקדמים } \left\{ \begin{array}{c}
\alpha+\beta=1 \\
\alpha+\beta=2 \\
\alpha+2\gamma=0
\end{array} \right\} \\
\left\{ \begin{array}{c}
\alpha+\beta=1 \\
\alpha+\beta=2
\end{array} \right\} \text{יש סתירה על } \\
1+2x\notin sp(\mathrm{S})\text{ ולכן }
\end{gathered}
```


טענה: יהי $`{}\mathrm{V}{}`$ מ"ו מעל $`{}\mathbb{F}{}`$ ותהי $`{}\mathrm{S}\subseteq\mathrm{V}{}`$ 
אזי (1) $`{}\mathrm{S}\subseteq sp(\mathrm{S}){}`$
ו (2) $`{}sp(\mathrm{S}){}`$ תת מרחב של $`{}\mathrm{S}{}`$
ו (3) לכל תת מרחב $`{}k\subseteq \mathrm{V}{}`$ מתקיים:


```math
sp(\mathrm{S})\subseteq K \impliedby \mathrm{S}\subseteq K
```


הוכחה: יהי $`{}\mathrm{V}{}`$ מ"ו מעל $`{}\mathbb{F}{}`$ . ותהי $`{}\mathrm{S}\subseteq \mathrm{V}{}`$ 
(1) נוכיח $`{}\mathrm{S}\subseteq sp\mathrm{S}{}`$: יהי $`{}v\in \mathrm{S}{}`$


```math
\begin{gathered}
v=1\cdot v\in sp(\mathrm{S})\\
\mathrm{S}\subseteq sp(\mathrm{S}) \ \text{ולכן}
\end{gathered}
```


	(2)
נחלק למקרים:
כאשר $`{}\mathrm{S}=\emptyset{}`$ אזי לפי הגדרה $`{}sp(\mathrm{S})=\left\{ \emptyset \right\}{}`$ וזה אכן ת"מ
כאשר $`{}\mathrm{S}\neq \emptyset{}`$ נוכיח $`{}sp(\mathrm{S}){}`$ ת"מ לפי קריטריון המקוצר:
	1. נראה $`{}0\in sp(\mathrm{S}){}`$ : $`{}\mathrm{S}{}`$  לא ריקה ולכן קיים לפחות איבר אחד, נבחר אחד כזה באופן שרירותי. נסמן $`{}\vec{s}{}`$ 


```math
\vec{0}= \underbrace{ 0 }_{ \mathbb{F} }\cdot \underbrace{ \vec{s} }_{ \mathrm{S} } \in sp\mathrm{S}
```


2. יהי $`{}v,u\in sp(\mathrm{S}){}`$ ויהי $`{}\alpha\in \mathbb{F}{}`$ .


```math
\begin{gathered}
\text{ כך ש } \begin{array}{c}
s_{1},\dots s_{n}\in \mathrm{S} \\
\alpha_{1},\dots\alpha_{n}\in \mathbb{F}
\end{array}\text{ קיימים} \text{ ולכן } v\in sp(\mathrm{S})\\
v=\alpha_{1}s_{1}+\dots+\alpha_{n}s_{n}\\
\\
\text{ כך ש } \begin{array}{c}
\tilde{s_{1}},\dots \tilde{s_{k}}\in \mathrm{S} \\
\beta_{1},\dots\beta_{k}\in \mathbb{F}
\end{array}\text{ קיימים} \text{ ולכן } u\in sp(\mathrm{S})\\
v=\beta_{1}\tilde{s_{1}}+\dots+\beta_{k}\tilde{s_{k}}\\ \\
\text{ כעת } \\
v+\alpha u=(\alpha_{1}s_{1}+\dots+\alpha_{n}s_{n})+\alpha(\beta_{1}\tilde{s_{1}}+\dots+\beta_{k}\tilde{s_{k}})\\
=\underbrace{ \alpha_{1} }_{ \in \mathbb{F} }\underbrace{ s_{1} }_{ \in \mathrm{S} }+\dots+\underbrace{ \alpha_{n} }_{ \in \mathbb{F} }\underbrace{ s_{n} }_{ \in \mathrm{S} }+\dots+\underbrace{ \beta_{1} }_{ \in \mathbb{F} }\underbrace{ \tilde{s_{1}} }_{ \in \mathrm{S} }+\dots+\underbrace{ \beta_{n} }_{ \in \mathbb{F} }\underbrace{ \tilde{s_{n}} }_{ \in \mathrm{S} }\\
v+\alpha u\in sp(\mathrm{S}):sp.\text{ולכן לפי ה} \\
\mathrm{V}\text{ ת"מ של }sp(\mathrm{S})\text{ סה"כ }
\end{gathered}
```


### מסקנה
יהי $`{}\mathrm{V}{}`$ מעל $`{}\mathbb{F}{}`$ ותהי $`{}\mathrm{S}\subseteq \mathrm{V}{}`$ אזי


```math
sp(\mathrm{S})=\mathrm{S} \iff \text{ת"מ}\ \mathrm{S}
```



טענה: יהי $`{}\mathrm{V}{}`$ מ"ו מעל $`{}\mathbb{F}{}`$ ותהיינה $`{}A,B\subseteq \mathrm{V}{}`$
אזי


```math
spA\subseteq spB \impliedby A\subseteq B
```
