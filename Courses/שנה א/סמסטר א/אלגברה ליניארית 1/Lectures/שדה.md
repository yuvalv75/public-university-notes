# שדה
הגדרה: קבוצה F עם פעולות חיבור וכפל, $`{}0_{f}, 1_{f}{}`$ נקראת שדה.
אם מתקיים:
1. סגירות: לכל 
$`{}a,b \in F,\space a * b \in F{}`$
2. קומוטוטיביות
 לכל $`{}a,b \in \space F{}`$ מתקיים:
 a+b = b + a, a*b = b*a
 3. אסוציאטיביות:
  לכל 
  $`{}a,b,c \space \in \space F{}`$ מתקיים
 (a+b) + c = a+(b+c)
 (a*b)*c = a(bc)
 
4. לכל 
  $`{}a,b,c \space \in \space F{}`$ מתקיים
  a(b+c) = a*b+ac

5. קיום ניטרלי לחיבור: קיים איבר ב F שנסמנו $`{}O_{F}{}`$ המקיים שלכל $`{}a \in F{}`$ :
a + $`{}o_{f}{}`$ = a

6. קיום ניטרלי לכפל:
קיים איבר ב F שנסמנו $`{}1_{F}{}`$ המקיים שלכל  $`{}a \in F{}`$ : 
$`{}1_{F} * a =a{}`$

7.קיום נגדי
לכל  $`{}a \in F{}`$ קיים איבר ב F שנסמנו (-a) המקיים:
a + (-a) = $`{}O_{F}{}`$
8. קיום הופכי
לכל 
$`{}O_{F} \neq a \in F{}`$
קיים איבר בF שנסמנו a^-1
a*$`{}a^-1{}`$ = $`{}1_{f}{}`$

טענות שנכונות בכל שדה:
*תכונת הצמצום*
טענה: יהי F שדה.
ויהיו $`{}a,b,c \space \in \space F{}`$ כך ש-
a + b = c + b
אזי
a = c

תמיד נתחיל בהוכחה ביהי F שדה, וגם:
$`{}a,b,c \space \in \space F{}`$

$`{}b \in F{}`$ ולכן יש לו נגדי, נחברו לשני האגפים


```math
\begin{gathered}
(a+b) + (-b) = (c+b) + (-b)\\
a + (\underbrace{ b+(-b) }_{ 0_{F} }) = c + (\underbrace{ b+(-b) }_{ 0_{F} }) \implies\\
\implies a = c
\end{gathered}
```



טענה: יהי F שדה
ויהי $`{}a \space \in \space F{}`$ 
$`{}a \cdot 0_{F} = 0_{F}{}`$
הוכחה:
יהי F שדה ויהי  $`{}a \space \in \space F{}`$ , כעת,


```math
\begin{gathered}
_{\text{מצד אחד}} a\cdot 0_{F} =0_{F} + \overbrace{ a\cdot 0_{F} }^{ \text{סגירות לחיבור} \in F } \\ \text{מצד שני:} \\ \\
a \cdot 0_{F} \overbrace{ =  }^{ \text{0 ניטרלי לחיבור} } a \cdot(0_{F} +0_{F}) = a\cdot 0_{F} + a\cdot 0_{F} \\ \\ \text{סה"כ קיבלנו} \\ \\
0 + a\cdot 0 = a\cdot 0 + a\cdot 0\\ \\
\text{תכונות הצמצום } \\
\text{יהי } a\cdot 0\in F \implies 0=0\cdot a
\end{gathered}
```
