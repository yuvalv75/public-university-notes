# מטריצות הפיכות ואלמנטריות
הגדרה:
תהי $`{}A\in\mathbb F^{nxm}{}`$ A נקראת הפיכה אם קיימת מטריצה B כך ש- 


```math
AB=BA=I
```


אז B כזאת נקראת הפכית ש A

מסקנה: משיקולי גדלים ($`{}\text{*}{}`$)  נקבל אם A הפיכה היא צריכה להיות ריבועית, כי אם לא, B משנה את גודלה משני הכיוונים וכך נקבל מטריצה יחידה שונה לשני המקרים.

טענה: תהי $`{}A\in\mathbb F^{nxn}{}`$ הפיכה,
אזי יש לה הופכית יחידה.
הוכחה:
תהי $`{}A\in\mathbb F^{nxn}{}`$ הפיכה
ויהיו $`{}B,C\in\mathbb F^{nxn}{}`$ הופכיות שלה (ולכן יש לה לפחות הופכית אחת).


```math
\begin{gathered}
\begin{cases}
AB\overbrace{ = }^{ 1 }I\overbrace{ = }^{ 2 }BA \\
AC\overbrace{ = }^{ 3 }I\overbrace{ = }^{ 4 }CA
\end{cases}\\
AB-AC \ \ \text{נובע ש } 1,3\\
\underbrace{ B }_{ \text{משמאל} }\text{נכפול ב } \\
B(AB)=B(AC)\overbrace{ \implies }^{ \text{אסוצ'} }\overbrace{ (BA) }^{ I }B=\overbrace{ (BA) }^{ I }C \overbrace{ \implies }^{ I+(2) }B=C
\end{gathered}
```



טענה:
תהי $`{}A\in\mathbb F^{nxn}{}`$
אזי A הפיכה =>$`{}A^{-1}{}`$ הפיכה ומתקיים
$`{}(A^{-1})^{-1}=A{}`$
להוכיח בבית

טענה:
תהי $`{}A\in\mathbb F^{nxn}{}`$
אזי A הפיכה =>$`{}A^{t}{}`$ הפיכה ומתקיים
$`{}(A^{t})^{-1}=A{}`$

הוכחה: תהי 
$`{}A\in \mathbb F^{nxn}  {}`$
$`{}(A^{-1})^{t}=(A^{t})^{-1}{}`$ צריך הסבר

טענה:
תהינה $`{}A,B\in\mathbb F^{nxn}{}`$ הפיכות.
אזי $`{}A\cdot B{}`$ הפיכה
הוכחה:
תהינה $`{}A,B\in\mathbb F^{nxn}{}`$ הפיכות.


```math
\begin{gathered}
(AB)\boxed{B^{-1}A^{-1}} \underbrace{ = }_{ \text{אסוצ} } A(\overbrace{ BB^{-1} }^{ I })A^{-1}  = AA^{-1}=I    \\
\boxed{B^{-1}A^{-1}}(AB) \overbrace{ = }^{  }B^{-1}(\underbrace{ A^{-1}A }_{ I })B=B^{-1}B=I
\end{gathered}
```


ולכן AB הפיכה ומתקיים:


```math
(AB)^{-1}=B^{-1}A^{-1}
```



טענה:
תהיינה $`{}A,B\in\mathbb F^{nxn}{}`$
אזי A וB הפיכות $`{}\leftrightarrow{}`$ AB הפיכה
הוכחה: תהיינה $`{}A,B\in\mathbb F^{nxn}{}`$ 
את -> הוכחנו
עכשיו הוכיח את <- 

נניח AB הפיכה
זאת אומרת שקיימת $`{}C\in\mathbb F^{nxn}{}`$ כך ש-


```math
\begin{gathered}
(AB)\boxed C = I =\boxed C(AB)\\
(AB)C=I \implies A(BC)=I\\
\text{ ולכן לפי טענה קודמת }
\\
A(BC)=I =(BC)A=I\\
 \text{ הפיכה } A\text{ולכן } \\
\text{ בנוסף, לפי השוויון ב2 נקבל }\\
C(AB)=I\\
\downarrow \text{אסוצ}\\
\text{ריבועית, טענה קודמת } \\
(CA)B=I=B(CA)
\end{gathered}
```


ולכן B הפיכה, סה"כ A,B הפיכות

הגדרה: תהי P פעולת שורה אלמנטרית
אזי P(I) נקראת מטריצה אלמנטרית.
[ הערה: P(A) הוא סימון המבטא להפעיל את P על מטריצה A ]
משפט: 
תהי $`{}A\in\mathbb F^{mxn}{}`$ Iתהי P פעולת שורה אלמנטרית
אזי $`{}P(A)=P(I)\cdot A{}`$
הוכחה:
תהי $`{}A\in\mathbb F^{mxn}{}`$ ותהי P פעולת שורה אלמנטרית

נחלק למקרים:
(1) $`{}P:\overbrace{ \alpha }^{ \neq 0 } R_{i}{}`$
עבור $`{}k\neq i{}`$


```math
\begin{gathered}
R_{k}(P(A))=R_{k}(A)\\
\overbrace{\alpha R_{i}(I) }^{ e_{i}^t }\cdot A\underbrace{ = }_{ k\neq i }R_{i}(P(I))\cdot A\underbrace{ = }_{ \text{כפל שורה שורה} }R_{i}(P(I)\cdot A) \\
\\ =P(I)\cdot A
\end{gathered}
```



טענה: תהי P פעולת שורה אלמנטרית אזי P(I) הפיכה ומתקיים


```math
(P(I))^{-1}=P^{-1}(I)
```


הוכחה: תהי P פעולת שורה אלמנטרית.


```math
\begin{gathered}
I=P^{-1}\cdot(P(I))\underbrace{ = }_{ \text{משפט קודם} } P^{-1}(I)\cdot P(I)\\
(P(I))^{-1}=P^{-1}(I)\text{ ומתקיים } \text{הפיכה } P(I)\begin{cases}
P^{-1}(I)\cdot P(I)=I \\
\text{ גם ריבועית } P(I)-\text{ולכן כיוון ש }
\end{cases}
\end{gathered}
```



טענה: תהיינה $`{}A,B\in\mathbb F^{mxn}{}`$ כך שניתן להגיע מA לB ע"י רצף פעולות שורה אלמנטריות $`{}P_{1},\dots,P_{k}{}`$
אזי A הפיכה <-> B הפיכה
הוכחה: תהיינה A,B כנ"ל
כלומר:


```math
\begin{gathered}
P_{k}(\dots P_{2}(P_{1}(A))\dots)=B\\
\text{ פעמים } k\ \text{משפט הקודם. נפעלו  } \downarrow\\
P_{k}(I)\cdot P_{k}(I)\dots P_{1}(I)\cdot A=B\\
P_{k}(I)\dots P_{1}(I)A=B\text{ הפיכה. אזי  } A\text{נניח  } \impliedby\\
\text{ הפיכה } B\text{והרי מכפלת הפיכות היא הפיכה ולכן } \\
\text{הפיכה } B\text{ נניח}\implies\\
\text{כלומר } \\
\text{הפיכה } P_{k}(I)\dots P_{1}(I)\\
\text{בריבועיות מכפלה הפיכה כך שכל אחת הפיכה } \\
\text{ הפיכה } A\text{ בפרט}
\end{gathered}
```
