# יחסים בין גבולות
![Pasted image 20261106083646](../../../../../Pasted%20image%2020261106083646.png)

### משפט
תהינה$`{}\{x_{n}\}{}`$ ו $`{}\{y_{n}\} {}`$ סדרות, נניח:


```math
\lim_{ n \to \infty } x_{n}=A, \lim_{ n \to \infty } y_{n}=B,\ \ A<B
```


אז יש $`{}N\in \mathbb{N}{}`$ כך שלכל $`{}n>N{}`$ מתקיים $`{}x_{n}<y_{n}{}`$ 
### הוכחה
ניקח C כלשהו עם $`{}A<C<B{}`$ 
אז:
1) יש $`{}N_{1}\in \mathbb{N}{}`$ כל שלכל $`{}n>N_{1}{}`$ מתקיים $`{}| x_{n}-A| <C-A{}`$  
2) יש $`{}N_{2}\in \mathbb{N}{}`$ כל שלכל $`{}n>N_{2}{}`$ מתקיים $`{}|y_{n}-B| <B-C{}`$  
יהי $`{}n>max\{N_{1},N_{2}\}{}`$


```math
\begin{gathered}
A-C<x_{n}-A<C-A\\
C-B<y_{n}-B<B-C\\ \downarrow\\
x_{n}<C<y_{n}\\
x_{n}<y_{n} \ \text{סה"כ}
\end{gathered}
```



# משפט הסנדוויץ'
תהיינה $`{}\{x_{n}\}, \{y_{n}\}, \{z_{n}\}{}`$ סדרות, ונניח  $`{}\lim_{ n \to \infty }x_{n}=\lim_{ n \to \infty }z_{n}=A{}`$, כמו כן נניח שיש $`{}N\in \mathbb{N}{}`$ כך שלכל $`{}n>N{}`$ מתקיים  $`{}x_{n}\leq y_{n}\leq z_{n}{}`$ .
 אז $`{}\lim_{ n \to \infty }y_{n}=A{}`$

### הוכחה
יהי $`{}\epsilon>0{}`$, יש $`{}N_{1}\in \mathbb{N}{}`$ כך שלכל $`{}n>N_{1}{}`$ מתקיים $`{}| x_{n-A}|<\epsilon{}`$  
יש $`{}N_{2}\in \mathbb{N}{}`$ כך שלכל $`{}n>N_{2}{}`$ מתקיים $`{}| z_{n-A}|<\epsilon{}`$  
יהי $`{}n>max\{N_{1},N_{2},N_{}\}{}`$ 


```math
\begin{gathered}
+A\begin{cases}
-\epsilon<x_{n}-A<\epsilon\\
-\epsilon<z_{n}-A<\epsilon
\end{cases}\\
A-\epsilon<x_{n}<A+\epsilon\\
A-\epsilon<z_{n}<A+\epsilon\\
\downarrow\\
A-\epsilon<x_{n}\leq y_{n} \leq z_{n}<A+\epsilon \\ \downarrow -A\\
-\epsilon<y_{n}-A<\epsilon \\ \downarrow\\
|y_{n}-A|<\epsilon
\end{gathered}
```

# קריטריון וויירשטראס
### משפט
תהי $`{}\{x_{n}\} {}`$ סדרה חסומה מלעיל ומונוטונית עולה. אז היא מתכנסת.
### הוכחה
תהי $`{}x=\{x_{n}|n\in N\}{}`$ .
אז $`{}x\neq \emptyset{}`$ וחסומה מלעיל.
יהי $`{}s=supx{}`$
יהי $`{}\epsilon>0{}`$ אז יש $`{}N\in \mathbb{N}{}`$
כך ש- $`{}x_{N}>s-\epsilon{}`$
ממונוטוניות, לכל $`{}n>N{}`$: $`{}x_{n}\leq x_{N}{}`$
כמו כן לכל n, $`{}x_{n}\leq s{}`$ 
יהי $`{}n>N{}`$:


```math
|x_{n}-s| = s-x_{n}\leq s-x_{N}<\epsilon
```
