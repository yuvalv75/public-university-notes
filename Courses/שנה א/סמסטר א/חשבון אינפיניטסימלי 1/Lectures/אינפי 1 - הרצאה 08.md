### הגדרה:
תהי $`{}\left\{ a_{n} \right\}_{n\in \mathbb{N}}{}`$ סדרה.
(1) נאמר ש "$`{}\left\{ a_{n} \right\}_{n\in \mathbb{N}}{}`$ שואפת לאינוסוף", ונסמן  $`{}\lim_{ n \to \infty }a_{n}=\infty{}`$ 
כאשר לכל M>0 קיים $`{}N\in \mathbb{N}{}`$ כך ש-
לכל n>N טבעי מתקיים $`{}a_{n}>M{}`$

(2) נאמר ש "$`{}\left\{ a_{n} \right\}_{n\in \mathbb{N}}{}`$ שואפת למינוס אינוסוף", ונסמן  $`{}\lim_{ n \to \infty }a_{n}=-\infty{}`$ 
כאשר לכל M<0 קיים $`{}N\in \mathbb{N}{}`$ כך ש-
לכל n>N טבעי מתקיים $`{}a_{n}<M{}`$

דוגמא:
נוכיח $`{}\lim_{ n \to \infty }2^n=\infty{}`$
יהי $`{}\tilde{M}>0{}`$ 


```math
\begin{gathered}
2^n>\tilde{M}\\
n> \lceil\log_{2}\tilde{M}\rceil
\end{gathered}
```



נחלק למקרים: $`{}\tilde{M}>1\ \ (I){}`$
ניקח $`{}N=\log _{c}\tilde{M}{}`$ כך שלכל n>N טבעי


```math
c^n>c^N=c^{\lceil\log_{c}\tilde{M}\rceil}\geq c^{\log_{c}\tilde{M}}=M
```


נראה $`{}\tilde{M}\leq 1\ \ (II){}`$
ניקח $`{}N=\lceil\log_{c}3\rceil{}`$ לפי $`{}(I){}`$ 
נקבל שלכל n>N מתקיים:


```math
c^n>3>\tilde{M}
```



### טענה 1
תהיינה $`{}\left\{ a_{n} \right\}_{n\in \mathbb{N}}{}`$ ,$`{}\left\{ b_{n} \right\}_{n\in \mathbb{N}}{}`$  סדרות, כך ש-


```math
\begin{gathered}
\lim_{ n \to \infty } a_{n}=\lim_{ n \to \infty } b_{n}=\infty\\
\lim_{ n \to \infty } a_{n}+b_{n}=\infty
\end{gathered}
```


הוכחה: יהי $`{}\tilde{M}>0{}`$ 


```math
\begin{gathered}
a_{n}> \frac{\tilde{M}}{2}\text{ טבעי } n>N_{1}\text{ כך שלכל } N_{1}\text{ נסמנו }N\in \mathbb{N}\text{ קיים } \frac{\tilde{M}}{2}\text{ ולכן בפרט עבור } \lim_{ n \to \infty } a_{n}=\infty\\
b_{n}> \frac{\tilde{M}}{2}\text{ טבעי } n>N_{2}\text{ כך שלכל } N_{2}\text{ נסמנו }N\in \mathbb{N}\text{ קיים } \frac{\tilde{M}}{2}\text{ ולכן בפרט עבור } \lim_{ n \to \infty } b_{n}=\infty
\end{gathered}
```


ניקח $`{}N=max\left\{ N_{1},N_{2} \right\}{}`$ אכן לכל n>N מתקיים


```math
a_{n}+b_{n}\underbrace{ > }_{ n>N\geq N_{1},N_{2} }\frac{\tilde{M}}{2}+\frac{\tilde{M}}{2}=\tilde{M}
```

### טענה 7
תהי $`{}\left\{ a_{n} \right\}_{n\in \mathbb{N}}{}`$   סדרה, כך ש-


```math
\lim_{ n \to \infty } a_{n}=\infty
```


אזי:
א) לכל $`{}0<c\in \mathbb{R}{}`$ מתקיים


```math
\lim_{ n \to \infty } c\cdot a_{n}=-\infty
```


הוכחה: 
תהי $`{}\left\{ a_{n} \right\}_{n\in \mathbb{N}}{}`$   סדרה, כך ש-


```math
\lim_{ n \to \infty } a_{n}=\infty
```


ויהי $`{}0<c\in \mathbb{R}{}`$ 
יהי $`{}M<0{}`$ 
נתון $`{}\lim_{ n \to \infty } a_{n}=\infty{}`$ אזי גם עבור $`{}\frac{M}{c}{}`$ (אכן $`{}\frac{M}{c}>0{}`$ כי שניהם קטנים מ0) קיים $`{}N\in \mathbb{N}{}`$ נסמנו $`{}N_{1}{}`$ כך שלכל $`{}n>N_{1}{}`$ טבעי מתקיים $`{}a_{n}>\frac{M}{c}{}`$ 

ניקח $`{}N_{1}{}`$ אכן לכל n>N מתקיים


```math
\begin{gathered}
a_{n}> \frac{M}{c}\\
ca_{n}<M\\
\text{ ולכן } \\
\lim_{ n \to \infty } c\cdot a_{n}=-\infty
\end{gathered}
```



### טענה 8
תהי $`{}\left\{ a_{n} \right\}_{n\in \mathbb{N}}{}`$   סדרה, כך ש-
א)


```math
\begin{gathered}
\lim_{ n \to \infty } a_{n}=\infty\\ a_{n}\neq 0
\end{gathered}
```


אזי:


```math
\lim_{ n \to \infty } \frac{1}{a_{n}}=0
```



ב)


```math
\begin{gathered}
\lim_{ n \to \infty } a_{n}=-\infty\\ a_{n}\neq 0
\end{gathered}
```


אזי:


```math
\lim_{ n \to \infty } \frac{1}{a_{n}}=0
```


הוכחה: 
א)
תהי $`{}\left\{ a_{n} \right\}_{n\in \mathbb{N}}{}`$   סדרה, כך ש-


```math
\lim_{ n \to \infty } a_{n}=\infty
```


יהי $`{}\tilde{\epsilon}>0{}`$ 
לא חייב אבל הראינו בכל מקרה: כיוון ש $`{}\lim_{ n \to \infty } a_{n}=\infty{}`$ ולכן בפרט עבור 1 קיים $`{}N\in \mathbb{N}{}`$  נסמן כזה $`{}N_{1}{}`$ כך שלכל $`{}n>N_{1}{}`$  טבעי $`{}a_{n}>1{}`$

כן חייב: כיוון ש $`{}\lim_{ n \to \infty } a_{n}=\infty{}`$ ולכן בפרט עבור $`{}\frac{1}{\tilde{\epsilon}}{}`$ אכן $`{}\frac{1}{\tilde{\epsilon}}>0{}`$  קיים $`{}N\in \mathbb{N}{}`$  נסמן כזה $`{}N_{2}{}`$ כך שלכל $`{}n>N_{2}{}`$ טבעי $`{}\frac{a_{n}>1}{\tilde{\epsilon}}{}`$ 
ניקח $`{}N=max\left\{ N_{1},N_{2} \right\}{}`$ כל שלכל n>N מתקיים


```math
\begin{gathered}
\left| \frac{1}{a_{n}}-0 \right|=\left| \frac{1}{a_{n}} \right| =\frac{1}{a_{n}} <\tilde{\epsilon}\\
\lim_{ n \to \infty } \frac{1}{a_{n}}=0\text{ ולכן }
\end{gathered}
```



### טענה 9


הוכחה:

```math

```


ונניח שלכל $`{}n\in \mathbb{N}{}`$ $`{}a_{n}>0{}`$

```math
\begin{gathered}
\frac{1}{a_{n}} = \left| \frac{1}{a_{n}} \right| = \left| \frac{1}{a_{n}-0} \right| >\tilde{M}\\
\lim_{ n \to \infty }\text{ ולכן }
\end{gathered}
```
