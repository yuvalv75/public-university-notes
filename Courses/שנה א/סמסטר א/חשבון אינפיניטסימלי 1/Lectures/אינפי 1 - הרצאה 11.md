### דוגמא
יהי $`{}q\in R{}`$ .      $`{}1+q+q^{2}+q^{3}+\dots{}`$ = $`{}\sum^\infty_{n=1}q^{n-1}{}`$ נקרא <u>טור גיאומטרי</u> 
נניח $`{}|q|<1{}`$ אז לכל $`{}n\in \mathbb{N}{}`$ 


```math
\begin{gathered}
s_{n}=\sum_{k=1}^nq^{n-1}= \frac{1-q^n}{1-q}\\
\sum^\infty_{n=1}q^{n-1}=\lim_{ n \to \infty } s_{n}=\lim_{ n \to \infty } = \frac{1-q^n}{1-q}=\frac{1-0}{1-q}=\boxed{\frac{1}{1-q}}
\end{gathered}
```



### משפט (קריטריון קושי לטורים)
הטור $`{}\sum_{n=1}^\infty a_{n}{}`$ מתכנסת $`{}\iff{}`$ לכל $`{}\epsilon>0{}`$ קיים $`{}n\in \mathbb{N}{}`$  כך שלכל $`{}m\geq n>N{}`$ מתקיים 


```math
\begin{gathered}
\left| \sum^m_{k=n}a_{k} \right| <\epsilon\\
\end{gathered}
```


### הוכחה
תהי$`{}\left\{ s_{n}  \right\} {}`$ סדרת הסכומים החלקיים
($`{}\impliedby{}`$)
נניח $`{}\left\{ s_{n} \right\}{}`$ מתכנסת. יהי $`{}\epsilon>0{}`$ 
מקריטריון קושי לסדרות יש $`{}N\in \mathbb{N}{}`$ כך שלכל $`{}m\geq n>N+1{}`$ מתקיים $`{}\left| s_{m}-s_{n} \right|<\epsilon{}`$ 
ברור ש- $`{}m,n-1>N{}`$ ולכן


```math
\begin{gathered}
\left| \sum_{k=n}^m a_{k}\right|= \left| s_{m}-s_{n-1} \right|<\epsilon\\
\end{gathered}
```


($`{}\implies{}`$)

נניח שהתנאי מתקיים (כיוון $`{}\impliedby{}`$), נוכיח $`{}\left\{ s_{n} \right\}{}`$ מתכנסת.
יהי $`{}\epsilon>0{}`$ אז יש $`{}N\in \mathbb{N}{}`$ כך שלכל $`{}m\geq n>N{}`$ :


```math
\begin{gathered}
\left| \sum_{k=n}^ma_{k} \right|<\epsilon\\
m,n>N\text{ יהיו} \\
\text{ אז } m=n \text{אם}\\
\left| s_{m}-s_{n} \right| =0<\epsilon
\end{gathered}
```


אחרת נניח בה"כ (בלי הגבלת הכלליות) ש- $`{}m>n{}`$ כלומר,$`{}m\geq n+1{}`$  אז:


```math
\begin{gathered}
\left| s_{m}-s_{n} \right| =\boxed{ \left| \sum^m_{k=n+1}a_{k} \right| <\epsilon}\\
\end{gathered}
```


### מסקנה
יהיו $`{}\sum_{n=1}^\infty a_{n},\sum_{n=1}^\infty b_{n}{}`$ טורים כך שרק במספר סופי של אינדקסים n מתקיים $`{}a_{n}\neq b_{n}{}`$ .
אז $`{}\sum_{n=1}^\infty a_{n}{}`$ מתכנס $`{}\sum_{n=1}^\infty b_{n}\iff{}`$ מתכנס.

### הוכחה
בה"כ נניח $`{}\sum_{n=1}^\infty a_{n}{}`$ מתכנס ונוכיח $`{}\sum_{n=1}^\infty b_{n}{}`$ .
יהי $`{}\epsilon>0{}`$ אז מקריטריון קושי לטורים יש $`{}N\in \mathbb{N}{}`$ כך שלכל $`{}m\geq n>N{}`$ : $`{}\left| \sum_{n=1}^\infty a_{k} \right|<\epsilon{}`$ 
יהי $`{}N\in \mathbb{N}{}`$ כך שלכל $`{}k>N'{}`$ : $`{}a_{k}=b_{k}{}`$ 
אז לכל $`{}m\geq n>max\left\{ N,N' \right\}{}`$ מתקיים


```math
\begin{gathered}
\left| \sum_{n=1}^\infty b_{n} \right|=\left| \sum_{n=1}^\infty a_{n} \right| <\epsilon\\
\boxed{\text{ מתכנס } \ \sum_{n=1}^\infty b_{n}\ \ \text{לכן}}
\end{gathered}
```



## דוגמא
הטור 


```math
\sum^\infty_{n} \frac{1}{n}
```


נקרא טור הרמוני

נוכיח שהוא מתבדר
ניקח $`{}\epsilon=\frac{1}{2}{}`$ , לכל $`{}N\in \mathbb{N}{}`$ ניקח:


```math
\begin{gathered}
n=N+1\ \ \ \ \ \ , \ \ \ \ \  m=2(N+1)\\
\boxed{\left| \sum_{k=N+1}^{2(N+1)} \frac{1}{k} \right|}= \frac{1}{N+1}+\frac{1}{N+2}+\dots+\frac{1}{2N+2}\\
\geq\\
\underbrace{ \frac{1}{2N+2} +\frac{1}{2N+2} +\frac{1}{2N+2} +\dots+\frac{1}{2N+2} }_{ \text{ איברים }N+2 }=\frac{N+2}{2N+2}\boxed{>} \frac{N+1}{2N+2}=\frac{1}{2}=\boxed{\epsilon}\\
 \boxed{\left| \sum_{k=N+1}^{2(N+1)} \frac{1}{k} \right|>\epsilon}\\
\end{gathered}
```



### משפט
אם $`{}\sum_{n=1}^\infty a_{n}{}`$ מתכנסת אז $`{}\left\{ a_{n}  \right\} {}`$ מתכנסת ל-0.
### הוכחה
מקריטיון קושי לטורים, לכל $`{}\epsilon>0{}`$ יש $`{}N\in \mathbb{N}{}`$ כך  שלכל $`{}n>N{}`$ מתקיים:


```math
\begin{gathered}
\left| a_{n}-0 \right| =\left| a_{n} \right| =\left| \sum_{k=n}^n a_{k} \right| <\epsilon\\
\end{gathered}
```
