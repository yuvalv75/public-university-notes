# משפט בולצאנו - ויירשטראס
- לכל סדרה חסומה יש תת סדרה מתכנסת
### הוכחה
תהי $`{}\left\{ x_{n} \right\}{}`$ סדרה חסומה, נוכיח שיש לה תת סדרה מונוטונית, תת סדרה זו תהיה חסומה גם כן.
מקריטריון ויירשטראס נקבל שתת הסדרה מתכנסת.

מספר $`{}k\in \mathbb{N}{}`$ נקרא אינדקס שיא אם  לכל $`{}m\ge k{}`$ מתקיים $`{}x_{k}\geq x_{m}{}`$ 
תהי E קבוצת אינדקסי השיא.
נחלק לשני מקרים:
1) E אינסופית
2) E סופית

מקרה 1:


```math
\begin{gathered}
n_{1}<n_{2}<n_{3}<\dots\ \ \ \text{ בסדרה } E\text{ נסדר את איברי  } \\
x_{n_{i}}\geq x_{n_{i+1}}\text{ מתקיים } i\in \mathbb{N}\text{ לכל } \\
\text{ מונוטונית יורדת } \left\{ x_{n_{i}} \right\} \text{ קיבלנו }
\end{gathered}
```



מקרה 2:


```math
\begin{gathered}
E \text{ שגדול מכל איברי}\ k\in \mathbb{N}\ \text{יהי}\\
 x_{m'}>x_{m}\text{ עם } m'>m\text{ אינו אינדקס שיא ולכן יש }m, m\geq k\text{ אז לכל } \\ \text{נגדיר}\\
 i\in \mathbb{N}\text{ ולכל }n_{1}=k\\
 n_{i+1}=n'_{i}\\
 n_{1}<n_{2}<n_{3}<\dots\text{ קיבלנו } \\
 x_{n_{1}}<x_{n_{2}}<x_{n_{3}}<\dots \text{ -ו}\\
 \text{ קיבלנו תת סדרה מונוטונית עולה }
\end{gathered}
```



# גבולות חלקיים


```math
\begin{gathered}
\underline{ \lim_{ k \to \infty }  }_{  }= \lim_{ k \to \infty } \inf_{k\geq n}  \\ \\
\overline{\lim_{ k \to \infty } } =\lim_{ k \to \infty } \sup_{k\geq n}
\end{gathered}
```

### למה
תהי $`{}\{a_{n}\}{}`$ סדרה מונוטונית עולה שגבולה c
אז $`{}a_{n}\leq c{}`$ לכל $`{}n\in \mathbb{N}{}`$ 

### משפט הגבולות החלקיים
תהי $`{}\left\{ x_{k} \right\}{}`$ סדרה חסומה. אז:
א) $`{}\underline{\lim_{ k \to \infty }}x_{k}{}`$ הוא הגדול החלקי הקטן ביותר שלה

ב) $`{}\overline{\lim_{ k \to \infty }}x_{k}{}`$  הוא הגבול החלקי הגדול ביותר שלה
### הוכחה
נוכיח רק את א כי ההוכחה סימטרית.

הסדרה $`{}\left\{ x_{k} \right\}{}`$ חסומה ולכן גם הסדרה $`{}i_{n}=\inf_{k\geq n}x_{k}{}`$ חסומה
כמו כן, קל לראות שהסדרה $`{}\left\{ i_{n} \right\}{}`$ מונוטונית עולה. 
מקריטריון ויירשטראס היא מתכנסת לאיזשהו $`{}c\in \mathbb{R}{}`$ 


```math
\underline{\lim_{ k \to \infty } }x_{n}=\lim_{ k \to \infty } i_{k}=c
```


נראה כי c הוא גבול חלקי:
יהי $`{}k_{0}=c{}`$ לכל $`{}n>0{}`$ נגדיר את $`{}k_{n}{}`$ כך:
יהי $`{}m=max(n_{1},k_{n-1}+1){}`$ 
אז $`{}i_{m}=\inf_{k\geq m}x_{k}{}`$ לכן $`{}i_{m}+\frac{1}{n}{}`$ אינו חסם מלרע של $`{}\left\{ x_{k}|k\geq m \right\}{}`$ 
כלומר יש $`{}k\geq m{}`$  עם $`{}x_{k}<i_{m}+ \frac{1}{n}{}`$
ניקח $`{}\boxed{k_{n}:=k}{}`$ 
כך יצרנו תת סדרה $`{}\left\{ x_{k_{n}} \right\}{}`$ כי $`{}k_{n}\geq m>k_{n-1}{}`$ 
לכל n:


```math
\begin{gathered}
i_{n}\leq x_{k_{n}} < i_{m}+\frac{1}{n} \leq c+\frac{1}{n}\\ \\
i_{n}\leq x_{k_{n}}:\\
\text{ אינפימום } i_{n}\text{ כי } \\ \\
 x_{k_{n}} < i_{m}+\frac{1}{n}:\\
 k_{n}\text{ כך בחרנו את  } \\ \\
 i_{m}+\frac{1}{n} \leq c+\frac{1}{n}:\\
 \text{ הלמה } \\ \\ \\
 i_{n}\to c\\
  c+\frac{1}{n}\to c
\end{gathered}
```


ממשפט הסנדוויץ הסדרה $`{}\left\{ x_{k_{n}} \right\} {}`$ מתכנסת ל- c

יהי d גבול חלקי של $`{}\left\{ x_{n} \right\}{}`$ ותהי $`{}\left\{ x_{k_{n}} \right\} {}`$ סדרה שמתכנסת ל -d
יהי $`{}n\in \mathbb{N}{}`$ . אז לכל $`{}i\geq n{}`$ מתקיים $`{}k_{i}\geq j\geq n{}`$ 
ולכן $`{}x_{k_{j}}\geq i_{j} {}`$ . 
ממשפט הסדר בין הגבולות נקבל ש$`{}c\leq d{}`$ 
מצאנו כי c הוא הגבול החלקי הכי קטן

### משפט
סדרה חסומה $`{}\left\{ x_{n} \right\}{}`$ מתכנסת אם ורק אם $`{}\underline{\lim_{ n \to \infty }}x_{n}=\overline{\lim_{ n \to \infty }}x_{n}{}`$ 
### הוכחה
נניח  $`{}\underline{\lim_{ n \to \infty }}x_{n}=\overline{\lim_{ n \to \infty }}x_{n}=A{}`$ 
נסמן


```math
\begin{gathered}
i_{n} = \inf_{k\geq m}x_{k}\\
s_{n}=\sup_{k\geq m}x_{k}\\
\lim_{ n \to \infty } x_{n}=A \ '\text{ממשפט הסנדוויץ}\\ \\ \implies
\end{gathered}
```


נניח $`{}\lim_{ n \to \infty } x_{n}=A{}`$ ראינו שכל תת סדרה של $`{}\left\{ x_{n} \right\} {}`$ גם מתכנסת ל-A. ולכן A הוא הגבול החלקי היחיד  של הסדרה. כלומר הוא הגבול החלקי הקטן והגדול ביותר לפי משפט הגבולות החלקיים
$`{}\underline{\lim_{ n \to \infty }}x_{n}=\overline{\lim_{ n \to \infty }}x_{n}=A{}`$
