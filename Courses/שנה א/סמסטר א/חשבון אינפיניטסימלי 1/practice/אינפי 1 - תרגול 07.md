# חשבון אינפיניטסימלי 1 - תרגול 7

### המספר e


```math
\lim_{ n \to \infty } \left( 1 + \frac{1}{n} \right)^n=e
```


### מסקנה


```math
a_{n}\to \infty \lor a_{n}\to-\infty\implies \lim_{ n \to \infty } \left( 1+ \frac{1}{a_{n}} \right)^{a_{n}}=e
```


##### הערה
נשתמש במסקנה כדי לפתור תרגילים מהצורה $`{}1^\infty{}`$ או $`{}1^{-\infty}{}`$ כלומר $`{}a_{n}^{b_{n}} {}`$ כך שמתקיים:


```math
\begin{gathered}
a_{n}\to 1\\
-ו\\
b_{n}\to \infty\\
וא\\
b_{n}\to-\infty
\end{gathered}
```


### תרגיל
מצאו את גבול הסדרה $`{}a_{n}= \left(  \frac{n+2}{n+1}  \right)^{-2n}{}`$ 
### פתרון
נשים לב כי $`{}a_{n} {}`$ הוא מהצורה של "$`{}1^\infty{}`$" משום שמתקיים:


```math
\left(  \frac{n+2}{n+1} \right)\to 1,\ \ \ \ -2n\to \infty
```


לכן ננסה להביא את הביטוי לצורה $`{}\left( 1+ \frac{1}{a_{n}} \right)^{a_{n}}{}`$ 


```math
\begin{gathered}
\left(  \frac{n+2}{n+1} \right)^{-2n}=\left( 1+\frac{n+2}{n+1}-1 \right)^{-2n}\\
= \left( 1+ \frac{n+2-(n+1)}{n+1} \right)^{-2n}\\
=\left( 1 + \frac{1}{n+1} \right)^{-2n}\\
\frac{n+1}{n+1}\text{ נכפיל את החזקה ב}\\
\left( \left( \underbrace{ 1+\frac{1}{n+1} }_{ e } \right)^{n+1} \right)^{-2n\cdot \frac{1}{n+1}}\\
\lim_{ n \to \infty } \left( \frac{n+2}{n+1} \right)^{-2n}=e^{\lim_{ n \to \infty }\frac {-2n}{n+1}}=e^{-2}
\end{gathered}
```


באופן כללי עבור ביטוי מהצורה $`{}a_{n}^{b_{n}}{}`$ 
כאשר $`{}a_{n}\to 1{}`$ וגם $`{}b_{n}\to \infty{}`$ נקבל


```math
\begin{gathered}
\lim_{ n \to \infty } a_{n}^{b_{n}} = \lim_{ n \to \infty } (1+a_{n}-1)^{b_{n}}\\
\lim_{ n \to \infty } (1+a_{n}-1)^{b_{n}\cdot\frac{a_{n}-1}{a_{n}-1}}\\
=\lim_{ n \to \infty } \left( (1+a_{n-1})^{\frac{1}{a_{n}-1}} \right)^{b_{n}(a_{n}-1)}\\
e^{\lim_{ n \to \infty } b_{n}(a_{n}-1)}\\
\lim_{ n \to \infty } a_{n}^{b_{n}}=e^{\lim_{ n \to \infty } b_{n}(a_{n}-1)} \text{ לכן } \\
b_{n}\to \pm \infty \land a_{n}\to 1 \text{ עבור}
\end{gathered}
```



ב)


```math
\lim_{ n \to \infty } \left( \frac{n+9}{n+7} \right)^{2n}
```


פתרון: נשים לב כי הביטוי מהצורה "$`{}1^\infty{}`$" כי 


```math
\frac{n+9}{n+7}\to 1, \ \ \ 2n\to \infty
```


לכן


```math
\begin{gathered}
\lim_{ n \to \infty } \left( \frac{n+9}{n+7} \right)^{2n}=e^{\lim_{ n \to \infty } 2n\left( \frac{n+9}{n+7}-1 \right)}\\
\lim_{ n \to \infty } 2n\left( \frac{n+9}{n+7}-1 \right)=\lim_{ n \to \infty } 2n\left( \frac{n+9-(n+7)}{n+7} \right)\\
=\lim_{ n \to \infty } 2n\left( \frac{2}{n+7} \right)\\
\lim_{ n \to \infty } \frac{4n}{n+7}= \lim_{ n \to \infty } \left( \frac{\left( \frac{4n}{n} \right)}{\left( \frac{n+7}{n} \right)} \right)\to \frac{4}{1+\underbrace{ \frac{7}{n} }_{ 0 }}\to 4\\
\lim_{ n \to \infty } \left( \frac{n+9}{n+7} \right)^{2n}=e^4 \text{ ולכן}
\end{gathered}
```



ג)


```math
\begin{gathered}
\lim_{ n \to \infty } \left( \frac{n^{2}-1}{n^{2}+2n} \right)^{n+\frac{1}{n}}\\
\end{gathered}
```


פתרון: נשים לב כי הביטוי מהצורה "$`{}1^\infty{}`$" כי 


```math
\begin{gathered}
n+\frac{1}{n}\to \infty, \frac{n^{2}-1}{n^{2}+2n}\to 1\\
\\
\lim_{ n \to \infty } \left( \frac{n^{2}-1}{n^{2}+2n} \right)^{n+\frac{1}{n}}= e^{\lim_{ n \to \infty }\left( n+\frac{1}{n} \right)\left( n+\frac{n^{2}-1}{n^{2}+2n} \right)-1 }\\
\lim_{ n \to \infty }\left( n+\frac{1}{n} \right)\left( n+\frac{n^{2}-1}{n^{2}+2n} \right)-1=
\\ \lim_{ n \to \infty }\left( n+\frac{1}{n} \right)\left( \frac{n^{2}-1-(n^{2}+2n)}{n^{2}+2n} \right)-1\\
\lim_{ n \to \infty }\left( n+\frac{1}{n} \right)\left( \frac{-2n-1}{n^{2}+2n} \right)-1\\
\lim_{ n \to \infty } \frac{-n^{3}-n^{2}-2n-1}{n^{3}+2n^{2}}=-2\\
\text{ ולכן } \\
\lim_{ n \to \infty } \left( \frac{n^{2}-1}{n^{2}+2n} \right)^{n+\frac{1}{n}}=e^{-2}
\end{gathered}
```



# תתי סדרות
תהי $`{}a_{n} {}`$ סדרה. סדרה שמוכלת ב $`{}a_{n} {}`$ היא תת סדרה.

- שL נקרא <u>גבול חלקי</u> של $`{}a_{n} {}`$ אם קיימת תת סדרה של $`{}a_{n}{}`$ שמתכנסת לL
### דוגמה


```math
a_{n}=(-1)^n
```


נתבונן ב $`{}a_{2k}{}`$ עבור $`{}k\in \mathbb{N}{}`$ נקבל $`{}a_{2k}=1,1,1,1,1\dotsm 1\to 1{}`$ 
ולכן 1 גבול חלקי של $`{}(-1)^n{}`$

- אם הסדרה מתכנסת ל-L כל תתי הסדרות שלה מתכנסות ל-L
- אם קיימות תתי סדרות שמכסות את כל הסדרה וכולן מתכנסות לL, אזי גם הסדרה מתכנסת לL

#### הערה
הרבה פעמים נשתמש ב2 תתי הסדרות $`{}a_{2k},a_{2k-1}{}`$ עבור $`{}k\in \mathbb{N}{}`$ 
- הגבול הכי גדול נקרא הגבול העליון ומסומן ב $`{}\overline{\lim_{ n \to \infty }}a_{n}{}`$ או $`{}\lim Sup_{ n \to \infty }{}`$ 
- הגבול החלקי הכי קטן נקרא הגבול התחתון $`{}\underline{\lim_{ n \to \infty }}a_{n}{}`$ או $`{}\liminf_{ n \to \infty }{}`$ 

###  משפט


```math
\overline{\lim}a_{n}=\underline{\lim }a_{n}=L \iff a_{n}\to L
```


### מסקנה
אם לסדרה יש שני גבולות חלקיים שונים אזי היא לא מתכנסת.


### משפט בולצאנו ויירשטראס
לכל סדרה חסומה יש תת סדרה מתכנסת.

### תרגיל
מצאו את הגבולות החלקיים:
א) $`{}a_{n}=\frac{5^n+(-5)^n}{4^n}{}`$ 
פתרון:
נחלק את $`{}a_{n}{}`$ ל2 תתי סדרות: $`{}a_{2k}, a_{2k-1}{}`$ עבור $`{}k\in \mathbb{N}{}`$ 
- נחשב גבול של $`{}a_{2k} {}`$ 


```math
\lim_{ n \to \infty } \frac{5^{2k}+(-5)^{2k}}{4^{2k}}= \frac{2\cdot 5^{2k}}{4^{2k}}=2\cdot\underbrace{ \left( \frac{5}{4} \right)^{2k} }_{ \infty }
```


ולכן $`{}\infty{}`$ הוא גבול חלקי של $`{}a_{n}{}`$

- נחשב גבול של $`{}a_{2k-1} {}`$ 


```math
\begin{gathered}
\lim_{ n \to \infty } \frac{5^{2k-1}+(-5)^{2k-1}}{4^{2k-1}}= \frac{2- 5^{2k-1}}{4^{2k-1}}=\frac{5^{2k-1}-5^{2k-1}}{4^{2k-1}}\\
=\frac{0}{4^{2k-1}}\to 0
```

# סדרות קושי
### הגדרה
נאמר ש $`{}a_{n}{}`$ היא סדרת קושי אם לכל $`{}\epsilon>0{}`$ קיים $`{}n_{\epsilon}\in \mathbb{N}{}`$ כך שלכל $`{}n,m>n_{\epsilon}{}`$ מתקיים:


```math
|a_{n}-a_{m}|<\epsilon
```


אינטואיטיבית איברי הסדרה הולכים ומתקרבים זה לזה.
### משפט:
תהי $`{}a_{n} {}`$ סדרה.
אז $`{}a_{n} {}`$ מתכנסת $`{}a_{n}\iff{}`$ סדרת קושי

### תרגיל
הוכיחו שהסדרה מתכנסת


```math
a_{n}= \frac{1}{1^{2}}+\frac{1}{2^{2}}+\frac{1}{3^{2}}+\dots+\frac{1}{n^{2}}
```


- השתמשו בהגדרה
  

```math
\frac{1}{x(x+1)}=\frac{1}{x}-\frac{1}{x+1}
```


#### פתרון
יהי $`{}\epsilon>0{}`$ . בה"כ (בלי הגדרת הכלליות) נאמר כי $`{}n>m{}`$ . נחשב


```math
\begin{gathered}
|a_{n}-a_{m}|=\left( \frac{1}{1^{2}}+\frac{1}{2^{2}}+\frac{1}{3^{2}}+\dots+\frac{1}{n^{2}} \right)-\left( \frac{1}{1^{2}}+\frac{1}{2^{2}}+\frac{1}{3^{2}}+\dots+\frac{1}{m^{2}} \right)\\
= \left( \frac{1}{1^{2}}+\frac{1}{2^{2}}+\frac{1}{3^{2}}+\dots+\frac{1}{m^{2}}+\frac{1}{(m+1)^2}+\dots+\frac{1}{n^{2}} \right)-\left( \frac{1}{1^{2}}+\frac{1}{2^{2}}+\frac{1}{3^{2}}+\dots+\frac{1}{m^{2}} \right)\\
=\frac{1}{(m+1)^2}+\frac{1}{(m+2)^2}+\dots+\frac{1}{n^{2}}\\
\frac{1}{(m+1)(m+1)}+\frac{1}{(m+2)(m+2)}+\dots+\frac{1}{n\cdot n} \\<
\frac{1}{(m)(m+1)}+\frac{1}{(m+2)(m+2)}+\dots+\frac{1}{(n-1)\cdot n}\\
=\frac{1}{m}-\centernot{\frac{1}{m+1}}+\centernot{\frac{1}{m+1}}+\centernot{\frac{1}{m+2}}+\dots+\centernot{\frac{1}{n-1}}-\centernot{\frac{1}{n}}\\
=\frac{1}{m}-\frac{1}{n}\\
|a_{n}-a_{m}|< \frac{1}{m}-\frac{1}{n}< \frac{1}{m}\text{ נזכור כי קיבלנו } \\
n_{\epsilon}=\lceil \frac{1}{\epsilon}\rceil\text{ולכן נבחר } \frac{1}{m}<\epsilon\text{ ולכן נדרוש }
\end{gathered}
```


ולכן $`{}a_{n}{}`$ היא סדרת קושי 
ולכן $`{}a_{n}{}`$ מתכנסת.
