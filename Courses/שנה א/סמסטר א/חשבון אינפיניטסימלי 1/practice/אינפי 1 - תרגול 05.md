# חשבון אינפיניטסימלי 1 - תרגול 5
# אריתמטיקה של גבולות
משפט:
אם $`{}a_{n}\to A\in R{}`$ וגם $`{}b_{n}\to B\in R{}`$ אזי 


```math
\begin{gathered}
a_{n}+b_{n}\to A+B\\
a_{n}-b_{n}\to A-B\\
a_{n}\cdot b_{n}\to A\cdot B\\
\frac{a_{n}}{b_{n}}\implies \frac{A}{B} \ \ \ \ B\neq 0 \ \text{עבור}
\end{gathered}
```

### משפט אפיסה כפול חסומה
אם $`{}a_{n}\to 0{}`$ (אפיסה) וגם $`{}b_{n}{}`$ חסומה (גם חסומה מלעיל וגם חסומה מלרע), אז:


```math
a_{n}\cdot b_{n}\to 0
```


### תרגיל 3
חשבו את הגבולות הבאים:
א) 


```math
\begin{gathered}
\lim_{ n \to \infty }
\frac{\sin(n)}{\log(n)}\\
\text{ פתרון } \\
\lim_{ n \to \infty } \sin(n)\cdot \frac{1}{\log(n)}\\
\lim_{ n \to \infty } \frac{1}{\log(n)}\to 0\\ \\
\left[ -1,1 \right] \text{ חסומה בתחום } \sin(n)\\
\\
\text{ שואפת ל0 } \frac{\sin(n)}{\log(n)}\text{ לכן לפי משפט אפיסה כפול חסומה }
\end{gathered}
```


ב)


```math
\begin{gathered}
\lim_{ n \to \infty } \frac{\sin ^{2}(n^{2})}{n^{3}+1}\\
\lim_{ n \to \infty } \sin ^{2}(n^{2})\cdot \frac{1}{n^{3}+1}\\
\lim_{ n \to \infty } \frac{1}{n^{3}+1}\to 0\\
\text{ חסומה  } \sin ^{2}(n^{2})\\
\text{ שואפת ל0 } \frac{\sin ^{2}(n^{2})}{n^{3}+1}\text{ לכן לפי משפט אפיסה כפול חסומה }
\end{gathered}
```
