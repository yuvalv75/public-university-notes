# Logical operators
|| logical OR
&& logical AND
! logical NOT

if something isnt 0 (false) it will be 1 (true)

on an OR statement, if the first half of the statement is false, it wont check the second half and will just skip it,
so if we went the second half to be accomplished then we need to put it on the first half.
for example:

```c
int x=2;
int y =3;
(x&&(y=7));
```
y=7 will not happen since x is already true, if we wanted y=7 to happen we would first need to put it in the first half.

# Expressions
a combination of operators and operands. or just an operand.
each expression has:
- type
- value
- address
a type and value are derived the operand's type and value

### RULE: the operands in an expression should be of the same type
either we can make it happen (explicit converion) or the compiler will make it happen even if we don't ask (implicit conversion).

# implicit conversion

invoked automatically by the compiler.
rule of thumb: expression converts to higher rank.

```c
double d = 2.5;
int a=3,b=4
a=b+d;
```
 b converted from int to double (promotion)
 b +d computed as double
 a is assigned the result, converting double to int.

# Explicit Conversion
invoked by the programmer's code, using (type)

```c
double d = 7.5;
int a = (int)d; // a is now 7
int b = 2;
int c = (double)a/b; // 7.0 / 2.0 =3.5 yet c is int so result would be 3
```
every demotion causes loss in data (use with caution).

# do-while
instead of being stuck in this:
```c
printf(...);
scanf(...);
while(condition){
printf(...);
scanf(...);
}
```
we can use do while to do this instead:
```c
do{
printf(...);
scanf(...);
}while(condition)
```
