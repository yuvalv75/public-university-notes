# Pointers
- a variable that contains the address of an object in the memory
* A pointer (to type) is usually associated with a type
stores addresses.
### Primitive types
```C
int
char
float
```
store values
### pointer types
```C
int*   // pointer to int
char*  // pointer to char
float* // pointer to float
```
stores addresses
### Declaring a pointer
```C
int a;  // regular variable
int *p; // pointer
```
the size of a pointer in bytes: 4 (in 32b) or 8 (in 64b) independent of its type.

# Pointer-related operators
- two important operators for handling pointers:
- Address operator &
	provides the address of a variable
-  Indirection Operator *
- access the variable whose address is held by the pointer
- Note: in declaration - * means “I am a pointer”, after that – used for indirection

# Passing arguments by address
• when calling the function, send the address of the variable
• The function receives the address, stored in a pointer
	• In a local variable within the function
• Can access to the original variable via operator *


# Pointers and arrays
- Recall: name of the array = address of the first element
- Assigning array to pointer: points to first element of array

# Pointers arithmetic operations
- Add/subtract integers to/from pointer.
- Jumps in "boxes" (elements).
	- determined by type of pointed variable.

# pointer relational operations
- comparing between pointers
	- compares the address contained in the pointer
- possible only if both are if the same type
- any pointer may be compared to the NULL (zero) pointer
	- recommended to check validity of a pointer before using it
	- in more complex programs
- >, < Commonly used for comparing pointers in an array
