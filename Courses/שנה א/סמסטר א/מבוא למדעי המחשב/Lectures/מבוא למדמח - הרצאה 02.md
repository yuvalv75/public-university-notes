# Negative Numbers
there are three ways of representing negative numbers in the binary system.
 the usual way of doing so is by "Two's complement".
the three ways are:
1)
### Sign & magnitude: 1-bit sign
MSB (most significant Bit) is a sign bit:
- 0 - positive
- 1 - negative


```math
\begin{array}{|c|c|c|}\hline
\color{green} MSB&  &  &  &  &  &  &  &  &  &  &  &  &  & \hline
\end{array}
```

the problem is that 0 can be represented by 2 different bit numbers, for example: 00000000 and 10000000.
another problem is that addition doesnt work:
0000 0101 =5
1000 0101 =-5
their addition gives us:
1000 1010 = -10

2)
# One's Complement
flip every bit in X to make it into -X. 1 becomes 0 and 0 becomes 1
example in 4 bits:
0111 = 7
1000 = -7

0 still becomes a problem here, it can be represented both by 0000 and 1111.
we also still get that MSB will be equal 1 and the negative numbers and equal to 0 in the positive numbers.

addition works perfectly in the One's Complement method!

# Data types

data types define:
- the kind of data a variable can hold
- how much memory it occupies
- how the system interprets that data

primitive data types
- int, char, float, long, double, (unsigned int, unsigned char)=>only positive numbers, ...

```C
int x = 2;
```
a number, usually 32 bits in memory.

- variable named x
- its data type is int
- it is initialized with the value 2
- when the program will run, it will be stored in the RAM (probably in 4 bytes)

in general a variable always has:
1. name
2. type
3. address
4. value
- name, type, address - never change, value may change
- if value hasn't been defined/assigned, the variable's value is "garbage"(Null)
- a variable must be declared before it is used
we can add "const"(constant) before int to lock its value into place, making it unchangeable.
