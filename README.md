# University notes

סיכומי הרצאות ותרגולים של יובל וויצנטובסקי.

ציורים מוצגים כתמונות במקום שבו הוטמעו בסיכומים. אפשר ללחוץ על תמונה כדי להגדיל.

הסיכומים עלולים לכלול שגיאות כתיב או טעויות אנוש אז לא מומלץ להסתמך רק על הסיכומים האלו.

אני אנסה לעדכן את מאגר הסיכומים כאשר אוכל, אם אתם צריכים שאעדכן משהו שעוד לא העליתי אפשר לכתוב לי בוואצאפ.
## תהנו!
